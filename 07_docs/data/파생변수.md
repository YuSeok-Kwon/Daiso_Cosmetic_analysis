다이소 화장품 데이터 분석을 위해 생성된 파생변수들의 정의, 생성 방법, 활용 목적을 설명한 문서입니다.

- **생성 파일**: `03_notebooks/2. Feature_engineering.ipynb`
- **출력 파일**: `data/products_with_features.parquet` (954개 상품, 19개 컬럼), `data/reviews_with_features.parquet` (326,752개 리뷰, 27개 컬럼)
- **최종 수정일**: 2026-02-16

## 1. Products DataFrame 파생변수 (8개)

### 1.1 review_count

- **설명**: 해당 제품에 달린 총 리뷰 개수
- **생성 방법**: `reviews_df.groupby('product_code').size()`
- **데이터 타입**: int
- **값의 범위**: 0 ~ 9,869
- **평균**: 344.57
- **활용 목적**: 제품 인기도 측정, engagement_score 계산에 사용

### 1.2 engagement_score

- **설명**: 제품의 전체적인 참여도를 나타내는 종합 지표
- **생성 방법**:

  ```
  engagement_score = 0.15 × likes + 0.30 × shares + 0.55 × review_count
  ```

  - 가중치는 각 지표의 변동계수(CV)를 기반으로 결정
  - review_count(CV 2.050) > shares(CV 1.884) > likes(CV 1.081) 순의 분별력
  - 변동계수가 높을수록 높은 가중치 부여

- **데이터 타입**: float
- **값의 범위**: 0 ~ 6,998.3 (평균 568.74)
- **활용 목적**: 제품의 종합적인 인기도 및 관심도 평가, 마케팅 우선순위 결정

### 1.3 price_tier

- **설명**: 다이소 기본 가격 체계를 기반으로 한 절대적 가격대 분류
- **생성 방법**:

  | 구간 | 조건 | 비율 |
  |------|------|------|
  | Easy Pick (Low) | ≤ 1,500원 | 5.9% (57개) |
  | Standard (Mid) | 1,501 ~ 3,000원 | 48.6% (464개) |
  | Premium (High) | ≥ 3,001원 | 45.4% (433개) |

- **데이터 타입**: str (categorical)
- **활용 목적**: 가격대별 전략 수립, 동일 카테고리 내 가격 경쟁력 분석

### 1.4 relative_price_ratio

- **설명**: 같은 소분류(category_2) 평균 대비 상대적 가격 비율
- **생성 방법**:
  ```
  relative_price_ratio = price / category_2별_평균_가격
  ```
- **데이터 타입**: float
- **값의 범위**: 0 이상의 실수 (1.0 = 카테고리 평균 가격)
- **해석**: 1.5 = 평균 대비 1.5배, 0.8 = 평균의 80% 수준
- **활용 목적**: 카테고리 내 가격 포지셔닝 분석

### 1.5 price_position

- **설명**: relative_price_ratio 기반 카테고리 대비 가격 포지션
- **생성 방법**:

  | 구간 | 조건 | 비율 |
  |------|------|------|
  | Cheaper than Avg | relative_price_ratio < 0.8 | 20.4% (195개) |
  | Average | 0.8 ~ 1.2 | 65.7% (627개) |
  | More Expensive than Avg | > 1.2 | 13.8% (132개) |

- **데이터 타입**: str (categorical)
- **활용 목적**: 경쟁 상품 대비 가격 전략 수립

### 1.6 cp_index

- **설명**: 가성비 지표 (Cost-Performance Index)
- **생성 방법**:

  ```
  cp_index = (engagement_score / price) × 1000
  ```

  - 1000을 곱하여 소수점 단위를 정수 범위로 정규화

- **데이터 타입**: float
- **값의 범위**: 수백 ~ 수천대 (높을수록 가성비 우수)
- **활용 목적**: 가격 대비 인기도 평가, 갓성비 상품 발굴

### 1.7 is_god_sung_bi

- **설명**: 갓성비 아이템 여부 (초저가 고효율 상품 플래그)
- **생성 방법**:
  - cp_index가 **상위 10%** (90 백분위수) 이상이면 1
- **데이터 타입**: int (0 또는 1)
- **값의 범위**: 0, 1
- **통계**: 갓성비 상품 95~96개, 평균 가격 약 3,000원
- **활용 목적**: 가성비 우수 제품 필터링, 입점 추천 및 집중 육성 제품 선정

### 1.8 review_density

- **설명**: 좋아요 수 대비 리뷰 작성 비율 (고객 반응성 지표)
- **생성 방법**:

  ```
  review_density = review_count / likes   (likes > 0일 때)
                 = 0                      (likes = 0일 때)
  ```

- **데이터 타입**: float
- **값의 범위**: 0 ~ 1.4727 (평균 0.1413)
- **해석**: 좋아요 1,000개당 약 141개의 리뷰 작성
- **활용 목적**: 진정성 있는 인기도 평가 (좋아요 대비 리뷰 참여율)

## 3. 파생변수 활용 가이드

### 3.1 제품 인기도 분석

- engagement_score: 종합적인 인기도 측정
- review_count: 리뷰 기반 인기도
- review_density: 좋아요 대비 리뷰 참여율

### 3.2 가격 전략 분석

- price_tier: 절대적 가격대 세분화 (다이소 가격 체계 기반)
- price_position: 카테고리 내 상대적 가격 포지셔닝
- relative_price_ratio: 카테고리 평균 대비 비율
- cp_index: 가성비 평가
- is_god_sung_bi: 고가성비 제품 식별 (상위 10%)

### 3.3 고객 행동 분석

- is_reorder: 재구매 여부 (RQ1 핵심)
- user_activity_level: 활동 수준 (VIP/Regular/Junior/Newbie)
- user_rating_tendency: 평점 성향
- is_brand_repurchase: 브랜드 충성도
- is_category_repurchase: 카테고리 선호도

### 3.4 시계열 분석

- year, month, season: 시간대별 트렌드
- day_of_week, day_name: 요일별 패턴
- is_new_product: 신제품 성과
- days_since_first_review: 제품 수명 주기

### 3.5 마케팅 효과 분석

- is_during_promo: 프로모션 영향
- promo_type_category: 프로모션 유형별 효과 (Review Event vs Purchase Event)

### 3.6 RQ별 핵심 파생변수

| 비즈니스 질문 | 핵심 파생변수 |
|---|---|
| RQ1: 재구매 핵심속성 | is_reorder, engagement_score, user_activity_level, is_brand_repurchase |
| RQ2: 저가 듀프 시장 | price_tier, cp_index, is_god_sung_bi, relative_price_ratio |

| 물류 최적화 | review_density, review_count, is_new_product |
| 프로모션 효과 | is_during_promo, promo_type_category, user_total_reviews |

## 4. 주의사항

1. **결측치 처리**
   - user_avg_rating_reorder: 재구매 리뷰가 없는 사용자는 NaN
   - promo_type_category: 프로모션 기간이 아닌 리뷰는 'No Promo'

2. **데이터 의존성**
   - is_brand_repurchase, is_category_repurchase: products 테이블과 조인 필요
   - is_during_promo, promo_type_category: promotion.csv 필요

3. **계산 제약**
   - cp_index: price가 0인 경우 대비 필요
   - review_density: likes가 0인 경우 0으로 처리
   - relative_price_ratio: category_2별 평균 가격 기반

   - 프로모션 관련 변수는 +7일 윈도우 기준이므로 정확도 한계 존재
   - is_god_sung_bi는 상위 10% 기준
