## 1. 한 줄 요약

Stage 1 골든셋 평가에서 발견된 3가지 구조적 문제(미분류 붕괴, 과다 검출, neutral 실종)를 해결하기 위해 **8 aspect 재학습 + F0.5 threshold + negative sampling**을 적용. Val Aspect-Sentiment F1 = **0.6686**, Threshold 튜닝 후 Detection F1 평균 = **0.67**. 다음 단계는 골든셋 Test 세트로 최종 평가.

## 2. Stage 2란?

```
Stage 1: GPT-4o 자동 라벨 17,132개 → 11 aspect 학습 → 골든셋 평가 → 구조적 문제 발견
Stage 2: 구조 개편(8 aspect) + 데이터 보강 + F0.5 재학습                   ← 이 문서
Stage 3: (예정) 골든셋 파인튜닝 → 최종 추론
```

Stage 1 골든셋 평가 결과, 3가지 핵심 문제가 확인되었다:

| 문제                   | 현상                                 | 원인                        |
| ---------------------- | ------------------------------------ | --------------------------- |
| **미분류 붕괴**  | 모델이 93.8%를 neutral로 예측        | "미분류=neutral" 강제 학습  |
| **과다 검출**    | Detection Precision = 0.51           | F1 최적화는 recall 편향     |
| **neutral 실종** | 대부분 aspect에서 neutral 예측 = 0건 | 학습 데이터 내 neutral 극소 |

Stage 2는 이 문제를 코드 구조 수준에서 해결한다.

## 3. Stage 1 → Stage 2: 무엇이 바뀌었는가?

### 3.1 구조 변경 요약

| 변경 항목         | Stage 1            | Stage 2                   | 이유                                   |
| ----------------- | ------------------ | ------------------------- | -------------------------------------- |
| Aspect 수         | 11개               | **8개**             | 미분류·CS/응대·품질/퀄리티 제거      |
| 미분류 처리       | 모델 학습          | **후처리**          | 10개→0이면 미분류=neutral 파생        |
| Threshold 메트릭  | F1                 | **F0.5**            | Precision 4배 가중 → 과다 검출 억제   |
| Polar threshold   | 없음               | **0.55**            | P(pos), P(neg) < 0.55이면 neutral 복원 |
| 데이터 분할       | 단일 CSV 자동 분할 | **Pre-split 3파일** | 보강 데이터 오염 방지                  |
| Negative sampling | 없음               | **디자인 2,500건**  | mask=0 → confirmed none 전환          |
| 모델 출력 shape   | [B, 11, 4]         | **[B, 8, 4]**       | 불필요 head 제거                       |

### 3.2 현재 8개 Aspect

```
배송/포장 │ 가격/가성비 │ 사용감/성능 │ 용량/휴대
디자인    │ 재질/냄새   │ 재구매      │ 색상/발색
```

제거된 3개:

- **미분류**: 후처리로 전환 (8개 aspect 전부 none → 미분류=neutral)
- **CS/응대**: 골든셋 884건 중 positive=1건, neutral=1건 → 학습 불가능
- **품질/퀄리티**: "사용감/성능"과 경계 모호, 오분류 심각

### 3.3 Keyword Gate (추론 시 적용)

모델이 non-none으로 예측해도 해당 aspect 키워드가 텍스트에 없으면 none으로 override하는 후처리:

```
디자인 키워드 (18개):
  Tier1 (구조물): 용기, 뚜껑, 케이스, 패키지, 디자인, 스포이드, 펌프, 튜브
  Tier2 (외관):   예쁘, 이쁘, 귀엽, 귀여, 깔끔, 고급, 앙증
  Tier3 (마감):   팁, 입구, 마감
```

## 4. 데이터 준비

### 4.1 Train/Val/Test 분할 (Pre-split)

원본 `absa_wide_train.csv` (17,132 리뷰)를 먼저 70/15/15로 분할한 후, train에만 보강을 적용한다. Val/Test는 자연 분포를 유지하여 일반화 검증에 사용.

```
원본 17,132 리뷰
    ├── Train 70% → 11,992 리뷰  → negative sampling 적용 → 저장
    ├── Val   15% →  2,570 리뷰  → 원본 그대로 저장
    └── Test  15% →  2,570 리뷰  → 원본 그대로 저장
```

**층화 기준:** review_sentiment (negative/neutral/positive)

### 4.2 Negative Sampling (디자인)

**문제:** 디자인 aspect는 mask=0(미라벨)이 약 11,000건으로, 모델이 "none이 무엇인지" 학습할 데이터가 부족했다.

**해결:** mask=0인 리뷰 중 디자인 키워드가 하나도 없는 것을 "confirmed none"으로 전환

```
변환 규칙:
  (1) mask=0이고
  (2) 디자인 키워드 24개 중 0개 포함이고
  (3) per-review 변환 cap (MAX_CONVERSIONS_PER_REVIEW=1) 미도달
  → mask=1, label=0 (confirmed none)
```

**보강 결과 (디자인):**

| 항목                     | 보강 전 | 보강 후            |
| ------------------------ | ------- | ------------------ |
| mask=0 (미라벨)          | 7,834   | 5,334              |
| mask=1 (학습 대상)       | 4,158   | **6,658**    |
| label=0 (none) 중 mask=1 | 2,345   | **4,845**    |
| 보강 건수                | -       | **+2,500건** |

**키워드 필터 효과:** 24개 키워드로 8,455건 중 2,500건을 안전하게 전환 (키워드 1개라도 포함된 리뷰는 건드리지 않음)

### 4.3 골든셋 Dev/Test 분할

`golden_set_wide_full_eval.csv` (884건)을 70/30으로 분할:

```
골든셋 884 리뷰
    ├── Dev  70% → 618 리뷰  (threshold 튜닝용)
    └── Test 30% → 266 리뷰  (최종 평가용)
```

**층화 기준:** review_sentiment × 디자인 언급 여부 (복합 층화)

- 디자인 같은 희소 aspect가 test에 몰리거나 빠지는 것을 방지
- Dev: 디자인 81건, Test: 디자인 34건

## 7. None-Threshold 튜닝 (F0.5)

### 7.1 Stage 1 대비 변경점

| 항목            | Stage 1          | Stage 2                   |
| --------------- | ---------------- | ------------------------- |
| 메트릭          | Macro F1         | **F-beta (β=0.5)** |
| Precision 가중  | 1배              | **4배**             |
| Polar threshold | 없음             | **0.55**            |
| 목적            | Detection 최적화 | **과다 검출 억제**  |

**F0.5 수식:**

```
F_β = (1 + β²) × P × R / (β² × P + R)   (β=0.5)
    = 1.25 × P × R / (0.25 × P + R)
```

Precision을 Recall보다 4배 중시한다. 즉, "언급됐다고 했는데 실제로는 아닌" 오탐을 강하게 억제.

### 7.2 튜닝 결과

| Aspect           | Threshold      | F1 (4-class) | Detection F1 | 해석               |
| ---------------- | -------------- | ------------ | ------------ | ------------------ |
| 사용감/성능      | **0.10** | 0.6828       | 0.9263       | 거의 항상 "언급됨" |
| 색상/발색        | **0.10** | 0.6835       | 0.8127       | 적극적으로 잡아냄  |
| 가격/가성비      | **0.10** | 0.5080       | 0.7108       | 적극적             |
| 배송/포장        | 0.15           | 0.5063       | 0.6180       | 중간               |
| 재질/냄새        | 0.15           | 0.4937       | 0.6387       | 중간               |
| 재구매           | 0.15           | 0.6848       | 0.8537       | 중간               |
| 용량/휴대        | 0.20           | 0.5407       | 0.5825       | 보수적             |
| **디자인** | **0.50** | 0.2966       | 0.1860       | 매우 보수적        |

**전체 효과:**

```
Threshold 튜닝 전 (default=0.5): Macro F1 = 0.6442
Threshold 튜닝 후:                Macro F1 = 0.7150  (+0.071, +11.0% 개선)
```

### 7.3 Polar Threshold

```
polar_threshold = 0.55
```

**작동 방식 (3단계 threshold):**

```
Step 1: P(none) >= t_none    → none (해당 aspect 미언급)
Step 2: max(P(pos), P(neg)) < t_polar → neutral (감성 확신 없음)
Step 3: else → argmax(pos, neg)        → positive 또는 negative
```

neutral이 학습 데이터에서 극소(1,356건, 전체의 3.1%)이므로, 모델이 neutral을 직접 예측하기 어렵다. 대신 "positive도 negative도 확신 못하는 경우"를 neutral로 복원하는 방식.

## 8. Stage 1 vs Stage 2 비교

### 8.1 Val Set 기준 비교

| 지표                     | Stage 1 | Stage 2 | 변화   |
| ------------------------ | ------- | ------- | ------ |
| Aspect-Sentiment F1      | 0.7507  | 0.6686  | -0.08  |
| Detection F1 (tuning 전) | 0.8181  | 0.8017  | -0.02  |
| Sentiment Acc            | 0.8467  | 0.8467  | ±0.00 |
| Sentiment F1             | 0.8395  | 0.8395  | ±0.00 |

**왜 Val F1이 낮아졌는가?**

- Stage 1은 11 aspect (미분류 포함) → 미분류 F1이 높아서 평균 부풀림
- Stage 2는 8 aspect → 미분류·CS·품질 제거로 "쉬운 aspect"가 빠짐
- 따라서 Val F1의 직접 비교는 의미가 제한적. **골든셋 평가가 진짜 비교 기준**

### 8.2 Threshold 기준 비교

| Aspect      | Stage 1 Threshold | Stage 2 Threshold | 변화         |
| ----------- | ----------------- | ----------------- | ------------ |
| 배송/포장   | 0.35              | **0.15**    | ↓ 더 적극적 |
| 가격/가성비 | 0.20              | **0.10**    | ↓           |
| 사용감/성능 | 0.10              | 0.10              | =            |
| 용량/휴대   | 0.25              | **0.20**    | ↓           |
| 디자인      | 0.55              | **0.50**    | ↓ 미세      |
| 재질/냄새   | 0.25              | **0.15**    | ↓           |
| 재구매      | 0.25              | **0.15**    | ↓           |
| 색상/발색   | 0.15              | **0.10**    | ↓           |

**추세:** F0.5 메트릭이 precision을 가중하므로, threshold가 전반적으로 낮아져 "더 적극적으로 detection"하면서도 precision을 유지하는 방향으로 튜닝됨.

### 8.3 디자인: 여전한 약점

| 디자인 지표         | Stage 1              | Stage 2              |
| ------------------- | -------------------- | -------------------- |
| Val Detection F1    | ~0.00 (threshold 전) | 0.094 (threshold 전) |
| Threshold 후 Det.F1 | 0.205 (골든셋)       | 0.186 (Val)          |
| Threshold           | 0.55                 | 0.50                 |

Negative sampling +2,500건에도 불구하고 디자인 Detection은 여전히 매우 낮다. 이는:

1. "예쁘다", "촌스럽다" 같은 간접 표현을 모델이 잡지 못함
2. Confirmed none(label=0)을 많이 줬지만, positive/negative 실제 샘플이 여전히 부족
3. **Keyword Gate 후처리**가 추론 시 이를 보완할 수 있음
