## 9. v1 → v2 변경 비교

### 9.1 후처리 변경 사항

| 변경 | 내용 |
|------|------|
| **키워드 게이트 추가** | 가격/가성비, 재질/냄새, 용량/휴대 — 해당 키워드 없으면 none으로 전환 (FP 제거) |
| **키워드 Force-On 추가** | 재구매 — 텍스트에 "재구매" 포함 시 강제 활성화 (FN 복구) |
| **입력 데이터 변경** | reviews_text.csv → reviews_text_no_reorder.csv (재주문 접두사 제거) |

### 9.2 Aspect 언급률 비교

| Aspect | v1 (%) | v2 (%) | 변화 | 원인 |
|--------|--------|--------|------|------|
| 사용감/성능 | 47.11 | 49.37 | +2.26pp | 다른 aspect FP 제거 → 상대 비중 증가 |
| 색상/발색 | 11.98 | 12.38 | +0.40pp | 상대 비중 미세 증가 |
| 재구매 | 15.81 | 10.71 | -5.10pp | 입력 데이터 변경 (재주문 접두사 제거) |

| 디자인 | 2.47 | 2.47 | 0 | Design Rule 불변 |
| **용량/휴대** | **5.24** | **2.29** | **-2.95pp** | 키워드 게이트 FP 제거 |
| 배송/포장 | 2.53 | 2.28 | -0.25pp | 미세 변동 |
| **재질/냄새** | **4.12** | **1.67** | **-2.45pp** | 키워드 게이트 FP 제거 |

### 9.4 키워드 게이트 효과 요약

키워드 게이트는 해당 aspect 키워드가 텍스트에 없을 때 모델 예측을 none으로 override하여 False Positive를 제거한다. v2에서 3개 aspect의 부정률이 상승한 것은 FP(키워드 없는 오탐)가 제거되고 진성 언급만 남았기 때문이다.

| Aspect | v1 Neg 비율 | v2 Neg 비율 | 해석 |
|--------|-------------|-------------|------|
| 재질/냄새 | 19.8% | 30.2% | FP 제거 → 진성 불만 비율 상승 |
| 용량/휴대 | 16.6% | 20.9% | FP 제거 → 진성 불만 비율 상승 |
| 가격/가성비 | 0.5% | 0.3% | FP 제거, 긍정 주도 유지 |

## 10. 한계점 및 후속 과제

### 10.1 알려진 한계

| 한계 | 설명 | 영향 |
|------|------|------|
| 디자인 과소검출 | 키워드 규칙 기반으로 2.47%만 검출 (Golden Test 8.3%) | 디자인 관련 인사이트가 과소 반영될 수 있음 |
| 재질/냄새 neutral 비율 | 60.8%가 neutral — "향이 있다" 류의 중립적 표현 다수 | 실제 불만이 neutral로 분류될 가능성 |
| 미분류 28.7% | 약 3개 중 1개 리뷰는 8개 aspect에 해당하지 않음 | "좋아요", "만족" 등 일반적 표현이 분석에서 제외 |
| 입력 데이터 차이 | v2는 재주문 접두사 제거 파일 사용 → 재구매 언급률 하락 | v1과의 직접 비교 시 입력 차이 고려 필요 |

### 10.2 후속 과제

1. **연착륙 상품 분석**: 추론 결과를 상품별로 집계하여 연착륙 스킨케어 후보군 도출
2. **대시보드 연동**: aspect별 감성 추이를 Streamlit/Tableau 대시보드에 반영
3. **외국인 리뷰 분석**: 동일 모델로 외국인 구매 리뷰 추론 후 국적별 선호 aspect 비교
