# MFDS 기능성화장품 API 데이터 수집 파이프라인

- **최종 수정일**: 2026-02-19
- **소스 코드**: `05_src/03_mfds_api/`

---

## 1. 개요

### 1.1 목적

식품의약품안전처(MFDS)의 공공데이터 API 3종을 활용하여:

- products.parquet의 954개 제품에 대해 기능성화장품 여부 검증
- 미백, 주름개선, 자외선차단, 여드름 등 효능 정보 수집
- 성분 영문명, CAS 번호, 사용제한 정보 보강
- 기존 product_attributes.csv 데이터와 비교 검증 및 오류 수정

### 1.2 사용 API (3종)

| API                       | 용도           | 소스 코드                   |
| ------------------------- | -------------- | --------------------------- |
| 기능성화장품 보고품목정보 | 제품 효능 조회 | `functional_cosmetics.py` |

## 2. 전체 파이프라인 흐름

```
products.parquet (954건)
    │

    ├─[Phase 2] 미매칭 기능성 제품 ──→ 다중 키워드 검색 (by 브랜드, 2단어 조합, 고유명사)

    ├─[효능 판별] EE_NAME > EFFECT_YN > FLAG_NAME > SPF/PA 순서
    │
    ├─[수정본 보정] 기능성 화장품 분류_수정본.xlsx 기반 효능 추가 반영
    │
    └─[저장] products_mfds.parquet (314건)
```

### 3.3 2-Phase 매칭 전략

#### Phase 1: 브랜드명 기반 검색

products.parquet에서 추출한 고유 브랜드명으로 API를 조회하여, 해당 브랜드의 전체 보고품목을 확보한 후 제품명 유사도 매칭을 수행한다.

**검색 흐름:**

```
products.brand → 68개 고유 브랜드
    ↓ 각 브랜드명으로 ITEM_NAME 파라미터 검색
API 품목 리스트 확보
    ↓ 해당 브랜드의 products와 이름 매칭
매칭 결과 수집
```

**이름 매칭 단계** (`_match_product_to_api_items()`):

| 순서 | 방법             | 설명                                               |
| ---- | ---------------- | -------------------------------------------------- |
| 1    | 정규화 완전 일치 | 양쪽 이름을 `_normalize_name()`으로 정제 후 비교 |
| 2    | 포함 관계        | 한쪽이 다른 쪽을 포함 (최소 3글자)                 |
| 3    | 접두사 매칭      | 앞 7글자 이상 동일하면 후보, overlap ≥ 0.4        |

**이름 정규화 규칙** (`_normalize_name()`):

1. 대괄호/소괄호 내용 제거
2. 용량 정보 제거 (`10ml`, `50g`)
3. 세트 표기 제거 (`2*30개입`)
4. 특수문자 제거
5. 영문 브랜드 약어 → 한글 변환 (아래 별칭 참조)
6. 소문자 변환

**브랜드 별칭 매핑** (`_BRAND_ALIAS`):

| 영문 | 한글 (MFDS 등록명) |
| ---- | ------------------ |
| vt   | 브이티             |
| ahc  | 에이에이치씨       |
| cnp  | 씨엔피             |
| bb   | 비비               |
| cc   | 씨씨               |
| egf  | 이지에프           |

#### Phase 2: 미매칭 기능성 제품 다중 키워드 검색

Phase 1에서 매칭되지 않은 `functional=1` 제품을 대상으로, 제품명에서 추출한 다중 키워드로 재검색한다.

**키워드 추출 전략** (`_extract_search_keys()`):

| 우선순위 | 방법                                   | 예시                                  |
| -------- | -------------------------------------- | ------------------------------------- |
| 1        | "by" 뒤의 원 브랜드명                  | `셀퓨전씨` (from "... by 셀퓨전씨") |
| 2        | 인접 2단어 조합 (공백 제거)            | `에이지리뉴크림`                    |
| 3        | 핵심 고유명사 (4글자+, 일반 용어 제외) | `리들샷`, `카밍`                  |
| 4        | 전체 제품명 (공백 제거)                | `브이티리들샷퍼스트앰플`            |

**일반 용어 필터링** (`_GENERIC_TERMS`): `크림`, `세럼`, `로션`, `토너` 등 단독 검색에 부적합한 화장품 용어 30+개를 제외한다.

**검색 안전장치**: API 반환 건수가 500건 초과 시 빈 리스트 반환 (너무 일반적인 키워드 방어).

### 3.4 효능 판별 체계

기능성화장품의 효능은 4가지 데이터 소스를 우선순위에 따라 조합하여 판별한다.

#### 효능 판별 우선순위 (`parse_target_flag()`)

| 순위 | 소스               | 설명                              | 적용 대상               |
| ---- | ------------------ | --------------------------------- | ----------------------- |
| 1    | `EE_NAME`        | 효능효과명 텍스트에서 키워드 추출 | 주로 flag=1 (심사 제품) |
| 2    | `EFFECT_YN1/2/3` | 효능 플래그 (Y/N)                 | flag=2 (고시원료 제품)  |
| 3    | `FLAG_NAME`      | 3호(자외선차단)만 신뢰            | flag=3 전용             |
| 4    | `SPF`/`PA`     | 자외선차단지수 존재 여부          | 모든 flag               |

#### EE_NAME 키워드 매핑

`EE_NAME`은 심사 제품(flag=1)에 효능 텍스트가 기재된다. 복수 효능이 하나의 텍스트에 포함될 수 있다.

| 키워드              | 매핑 컬럼        |
| ------------------- | ---------------- |
| 미백                | is_whitening     |
| 주름개선            | is_anti_wrinkle  |
| 자외선 / 자외선차단 | is_sunscreen     |
| 모발의 색상         | is_hair_color    |
| 체모를 제거         | is_hair_removal  |
| 여드름              | is_acne          |
| 아토피              | is_atopic        |
| 튼살                | is_stretch_marks |
| 탈모                | is_hair_loss     |
| 눈가                | is_eye_wrinkle   |

#### EFFECT_YN1/2/3 필드

flag=2(고시원료 사용) 제품에서 `EE_NAME`이 없을 때 효능을 판별하는 보조 플래그:

| 필드       | Y일 때                     | 캐시 내 Y 건수 |
| ---------- | -------------------------- | -------------- |
| EFFECT_YN1 | 미백 (is_whitening)        | 472건          |
| EFFECT_YN2 | 주름개선 (is_anti_wrinkle) | 471건          |
| EFFECT_YN3 | 자외선차단 (is_sunscreen)  | 739건          |

> **참고**: flag=1 제품은 EFFECT_YN이 항상 'N'이므로, EE_NAME을 우선 사용한다. flag=2에서만 EFFECT_YN이 유의미하다.

#### COSMETIC_TARGET_FLAG 분류

API 응답의 9,600건 전체 캐시에서 flag=1, 2, 3만 존재한다.

| FLAG 값            | 효능            | 등록 방식        | 설명                                         |
| ------------------ | --------------- | ---------------- | -------------------------------------------- |
| 제10조 제1항 제1호 | 심사            | 효능 심사 (엄격) | EE_NAME에 효능 텍스트 기재                   |
| 제10조 제1항 제2호 | 고시원료        | 보고 (간소화)    | EFFECT_YN으로 효능 판별, SPF/PA 보유 가능    |
| 제10조 제1항 제3호 | 자외선차단 전용 | 보고 (간소화)    | 전원 SPF/PA 보유, FLAG만으로 자외선차단 확정 |

#### SPF/PA 기반 자외선차단 판별

`SPF` 또는 `PA` 값이 존재하고 "0"이 아니면 `is_sunscreen=True`로 설정한다.

- flag=2에서 SPF/PA 보유: 83건 → 자외선차단으로 분류
- flag=3 전원: 24건 → 자외선차단으로 분류
- flag=2에서 SPF/PA 미보유: 54건 → SPF/PA로는 미분류

### 3.5 수정본 효능 보정 (`_apply_manual_fix()`)

API의 EFFECT_YN/EE_NAME이 없는 flag=2 제품 등에 대해 수동 검수 결과를 반영한다.

**입력 파일**: `02_processed_data/기능성 화장품 분류_수정본.xlsx` (954행)

**보정 로직**:

1. 수정본의 `whitening` + `whitening2` (어느 하나라도 1이면 True)
2. 수정본의 `wrinkle_reduction` + `wrinkle_reduction2`
3. 수정본의 `sunscreen` + `sunscreen2`
4. 수정본의 `acne`
5. **추가만 수행**: 기존 True를 False로 덮어쓰지 않음 (API 결과 보존)
6. `product_code` 중복 시 첫 번째 행 사용 (`drop_duplicates`)

**보정 효과**:

| 효능       | API만 | + 수정본 보정 | 증가분 |
| ---------- | ----- | ------------- | ------ |
| 미백       | 131   | 205           | +74    |
| 주름개선   | 123   | 194           | +71    |
| 자외선차단 | 107   | 110           | +3     |
| 여드름     | 0     | 12            | +12    |

## 6. 심사품목 API (검토 결과: 불필요)

보고품목 API 외에 **심사품목 API**도 검토하였으나, 본 프로젝트에는 적합하지 않음.

| 항목      | 내용                                                                                  |
| --------- | ------------------------------------------------------------------------------------- |
| API명     | 기능성화장품 심사품목 정보                                                            |
| Endpoint  | `https://apis.data.go.kr/1471057/FtnltCosmSrngPrdlstInfoService04/getSrngPrdlstInq` |
| 총 데이터 | 약 20,080건                                                                           |

### 보고품목 vs 심사품목

| 구분                  | 보고품목 API             | 심사품목 API               |
| --------------------- | ------------------------ | -------------------------- |
| 대상                  | 기존 고시 원료 사용 제품 | 새로운 원료/배합 심사 제품 |
| 등록 방식             | 보고 (간소화)            | 심사 (엄격)                |
| **우리 브랜드** | **포함**           | 미포함                     |

테스트 결과 우리 브랜드(해서린, 드롭비, 메디필, CNP) 매칭 0건 → **불필요**
