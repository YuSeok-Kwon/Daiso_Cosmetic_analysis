2. 정규식 Gate의 장단점
================================================================================

✅ 장점:
  ✓ substring 대비 거짓양성 감소
    - 가격/가성비: "싸", "싼" 활용형으로 정확도 향상
    - 디자인: "깔끔", "고급" 부정 정규식으로 사용감 제외
  ✓ 문맥 기반 필터링으로 aspect 경계 명확화
  ✓ 전체적으로 보수적이고 정확한 필터링

⚠️ 단점:
  ✗ 용량/휴대 '오래' 패턴이 과도하게 엄격
    - 642건 추가 차단 (기존 통과 대비 7.4%)
    - 지속력과 용량의 경계 모호
  ✗ ABSA 모델과의 불일치 가능성
    - aspect_labels와 정규식 Gate 결과가 다를 수 있음
  ✗ 신규 통과 335건 미검증

4. 우선순위별 조치 사항
================================================================================

[P1] 즉시 조치 (이번 주)

  1. 용량/휴대 '오래' 패턴 재검토
     - 차단된 642건 중 '오래' 포함 182건 샘플 검토
     - ABSA 라벨 vs 실제 의미 비교
     - 패턴 완화 vs 유지 결정

  2. 가격/가성비 신규 통과 검증
     - 335건 중 50건 이상 직접 검토
     - 기존 substring '싸'와의 차이점 파악
     - 정규식 신뢰도 평가

[P2] 단기 조치 (2-3주)

  3. 디자인 부정 정규식 성능 검증
     - 차단된 56건이 정말 사용감을 의미하는가?
     - False Negative 비율 파악

  4. 정규식 Gate 문서화
     - 각 패턴의 의도, 문제점, 개선안 기록
     - 테스트 결과 정리

[P3] 중기 계획 (1개월)

  5. ABSA Stage 4C 정규식 Gate 통합
     - 모든 검증 완료 후 정식 적용
     - 필요시 재학습 검토

     - sentiment_score 기반 Gate 강도 조정
     - review_length 기반 신뢰도 반영
