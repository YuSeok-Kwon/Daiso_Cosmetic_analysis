## 2. Aspect별 상세 분석

### 2-1. 디자인 (Design)

**개요:**
- 해당 리뷰: 7,997건
- 기존 통과: 7,997건
- 새 통과: 7,941건
- **추가 차단: 56건 (0.70%)**
- 신규 통과: 0건

**원인 분석:**

#### (1) '깔끔' 부정 정규식 (50건 차단)

```regex
r"깔끔(?!\s*(?:하게\s*)?(?:흡수|발[라림]|바[르름]|마무리|사용))"
```

**의도:**  
- "깔끔하게 흡수됨" = 사용감 (습도감, 빠른 흡수율)
- "깔끔한 디자인" = 디자인 (외관, 패키징)
- 부정 정규식으로 사용감 의미를 제외

**예시 차단 리뷰:**
```
"끈적이는 사용감이나 번들거림 없이 깔끔하게 흡수돼요"
→ "깔끔하게 흡수" → 사용감이므로 Gate 차단 ✓
```

**평가:** ✅ 정규식 설계 우수 - 문맥 이해도 높음

#### (2) '고급' 부정 정규식 (6건 차단)

```regex
r"고급(?!\s*(?:스러운\s*)?(?:사용감|느낌|발림|텍스처))"
```

**의도:** "고급스러운 사용감" = 사용감이므로 제외

**평가:** ✅ 수정 불필요

### 2-2. 가격/가성비 (Price/Value)

**개요:**
- 해당 리뷰: 40,612건
- 기존 통과: 39,456건
- 새 통과: 39,767건
- 추가 차단: 24건 (0.06%)
- **신규 통과: 335건 (28.98%)**

**원인 분석:**

#### (1) 활용형 정규식 '싼/싸' (335건 신규 통과)

```regex
r"싸[다고게서니요네]",
r"싼\s*(?:거|것|편|가격|제품|데)",
r"(?<!잽)싸게"
```

**기존 substring의 문제:**

```python
"싸" in text  # substring 매칭
```

- "싸구" (상품명) → 오탐
- "싹" 포함 문자열 ("싹싹") → 오탐
- "싸기" → "싸다" 활용형이지만 광범위 매칭

**새 정규식의 개선:**

- "싸다", "싼거", "싼데", "싼편" 등 **명확한 활용형만** 매칭
- 문맥 제약 추가 (예: "(?<!잽)싸게" = "잽싸게" 제외)

**예시 신규 통과 리뷰:**
```
"좋아용 싼데 얇고 잘그려짐"
→ "싼데" = 정규식 매칭, 기존 substring '싼'은 "싼"에서 만족하지 않음
```

> ⚠️ 실제로는 기존 substring '싼'도 이 리뷰에서 매칭되어야 하는데,  
> 분석 방법상 substring 재검증 필요

**신규 통과 리뷰의 감성:**
- 긍정: 258건 (77.0%)
- 중립: 46건 (13.7%)
- 부정: 31건 (9.3%)

**평가:** ✅ 신규 통과 리뷰의 대다수가 긍정 감성 → 품질 양호

- 새 통과: 8,806건

**분석:**

거의 변화 없음. 정규식이 substring과 유사하게 작동함.

**차단 리뷰:**

→ 정규식 r"향(?!상|수[인를이]?\s|후[에를])" = 부정정규식으로 제외 ✓

### 2-4. 용량/휴대 (Capacity/Portability)

**개요:**
- 해당 리뷰: 8,694건
- 기존 통과: 8,686건
- 새 통과: 8,045건
- **추가 차단: 642건 (7.39%)** ⚠️ **가장 높음**
- 신규 통과: 1건 (12.50%)

**원인 분석:**

#### (1) '오래' 지속력 정규식 (182건 = 28.3%)

```regex
r"오래\s*(?:쓸|쓰[다고니]|쓸\s*수|사용|가[다요니]|버티|갈\s*것|갈\s*듯)"
```

**의도:**
- "오래 **사용**할 수 있다" = 지속력(성능) → aspect: 사용감/성능
- "오래 **쓸 수** 있어요" = 지속력(성능) → aspect: 사용감/성능
- "양이 많아서 오래 **갈 것** 같아요" = 용량과 지속력 혼합

**기존 substring의 문제:**

```python
"오래" in text  # 모든 "오래" = 용량/휴대로 판단
```

- "오래 사용할 수 있어요" → 기존: 용량, 새: 사용감 (분류 차이)
- 이는 정규식이 더 정확함을 의미

**예시 리뷰:**
```
"오래 쓸 수 있어서 좋아요"
→ 기존: 용량 판정 (부정확)
→ 새: 사용감 판정 (정확) ✓
```

**⚠️ 그러나 우려점:**

용량/휴대 aspect를 언급한 리뷰에서 '오래' 정규식이 차단하면,  
**aspect_labels에는 '용량/휴대'가 있지만 Gate는 통과하지 않는 상황 발생**

→ 이는 ABSA 모델이 "용량/휴대"를 감지했지만, 정규식 Gate가 "이건 사실 성능 이야기다"라고 판단

#### (2) 기타 정규식 엄격화 (460건)

- `\d+ ml`, `\d+ g` 패턴 정확도 향상
- `양` 한글 음절 제한 (`(?<![가-힣])양`) → "상량", "양옆" 등 오탐 방지
- "작다", "크다" → "작[다아은]", "크[다고게]" 활용형으로 정확도 향상

**평가:** ⚠️ **재검토 필요**

- 정규식이 기술적으로 정확하나, **aspect와의 불일치 발생**
- "용량/휴대" aspect를 언급한 리뷰 중 많은 수가 사실 "지속력"을 의미
- 정규식이 이를 올바르게 필터링 중 (기술상 정확)
- 그러나 비즈니스 관점에서는 "용량/휴대"로 분류된 리뷰를 버리는 것
