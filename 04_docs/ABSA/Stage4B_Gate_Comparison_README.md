## 주요 인사이트

### 정규식의 강점

1. **문맥 이해** - 부정 정규식(`(?! ...)`)으로 의미 구분
   - 예: "깔끔하게 흡수" → 사용감 (디자인 제외)

2. **활용형 인식** - 동사/형용사의 활용형으로 정확도 향상
   - 예: "싼거", "싼데", "싼편" (substring "싸"는 모두 매칭)

3. **거짓양성 제거** - 상품명이나 불관련 단어 제외
   - 예: "싸구", "싹싹" 등 오탐 방지

### 정규식의 약점

1. **과도한 엄격성** - 일부 패턴이 유효한 리뷰까지 차단
   - 예: '오래' 패턴이 지속력을 성능으로 재분류하면서 642건 차단

2. **Aspect 불일치** - ABSA 라벨과 정규식 판단 다름
   - 예: ABSA가 "용량/휴대"로 분류했으나 정규식이 "사용감"으로 판단

3. **미검증** - 신규 통과 335건이 정말 정확한지 확인 필요
