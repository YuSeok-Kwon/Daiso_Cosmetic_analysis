## 1. 한 줄 요약

Stage 3A 운영 번들로 **323,114건 리뷰**를 56.5분 만에 추론 완료. 사용감/성능(47.1%)이 압도적 언급률 1위, 리뷰 69%가 긍정, 미분류 24.7%.

## 2. 실행 개요

### 2.1 파이프라인

```
reviews_text.csv (323,114건)
    ↓ pd.read_csv(chunksize=10,000)
    ↓ ABSAInference.from_bundle() — MD5 검증 후 로드
    ↓ [청크별 추론]
    │   ├─ KcELECTRA 토크나이저 + 모델 predict
    │   ├─ none-threshold 적용 (aspect별 개별 threshold)
    │   ├─ polar-threshold 적용 (0.50)
    │   ├─ Design Rule Override (디자인 aspect 키워드 대체)
    │   └─ keyword gate (사용감/성능 키워드 사후 보정)
    ↓ streaming CSV append
absa_results_stage3a_full.csv + summary.json
```

## 7. 출력 파일 명세

### 7.1 absa_results_stage3a_full.csv

| 컬럼              | 타입      | 설명                                                                               |
| ----------------- | --------- | ---------------------------------------------------------------------------------- |
| review_id         | str       | 리뷰 ID                                                                            |
| text              | str       | 원문 텍스트                                                                        |
| review_length     | int       | 텍스트 길이                                                                        |
| sentiment         | str       | 리뷰 전체 감성 (positive/neutral/negative)                                         |
| sentiment_score   | float     | P(positive) - P(negative), [-1, 1]                                                 |
| aspect_sentiments | str(JSON) | aspect별 감성 리스트 (예:`[{"aspect": "사용감/성능", "sentiment": "positive"}]`) |
| aspect_labels     | str       | 파이프 구분 aspect 목록 (예:`사용감/성능\|재구매`)                                |
| summary           | str       | 자연어 요약 (예:`사용감/성능(+) 재구매(+)`)                                      |
| is_ambiguous      | bool      | 전체 감성과 aspect 감성 불일치 여부                                                |

### 7.2 absa_results_stage3a_summary.json

전체 추론 통계 요약 (aspect 언급률, 감성 분포, 처리 시간 등).

## 9. 한계점 및 후속 과제

### 9.1 알려진 한계

| 한계                   | 설명                                                 | 영향                                             |
| ---------------------- | ---------------------------------------------------- | ------------------------------------------------ |
| 디자인 과소검출        | 키워드 규칙 기반으로 2.47%만 검출 (Golden Test 8.3%) | 디자인 관련 인사이트가 과소 반영될 수 있음       |
| 재질/냄새 neutral 과잉 | 75.5%가 neutral — "향이 있다" 류의 중립적 표현 다수 | 실제 불만이 neutral로 분류될 가능성              |
| 미분류 24.7%           | 4개 중 1개 리뷰는 8개 aspect에 해당하지 않음         | "좋아요", "만족" 등 일반적 표현이 분석에서 제외  |
| 골든셋 대비 편차       | 가성비/재구매 등 골든셋 대비 언급률 차이             | 골든셋 샘플링 편향이 원인, 전체 분포가 더 대표적 |

### 9.2 후속 과제

1. **Stage 3B (선택)**: 디자인/재질/냄새 약점 aspect에 대한 추가 라벨링 + 재학습
2. **연착륙 상품 분석**: 추론 결과를 상품별로 집계하여 연착륙 스킨케어 후보군 도출
3. **대시보드 연동**: aspect별 감성 추이를 Streamlit/Tableau 대시보드에 반영ㅇ
4. **외국인 리뷰 분석**: 동일 모델로 외국인 구매 리뷰 추론 후 국적별 선호 aspect 비교
