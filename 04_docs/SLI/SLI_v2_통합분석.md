## 1. 핵심 개념 가이드

### ① SLI_v2 (Soft Landing Index v2)

기존 SLI(v1)가 3구간(early/mid/late) + 단순 비율 + polyfit 기울기를 사용한 반면, **SLI_v2**는 4구간 + 로그 차이 + 비대칭 기울기로 설계된 개선 버전입니다.

* **polyfit :** 데이터 분석에서 데이터들의 흐름을 가장 잘 나타내는 직선이나 곡선을 찾아주는 수학적 도구. 복잡하게 흩어진 점들 사이에서 하나의 대표적인 법칙(수식)을 찾아낼 때 사용합니다.

```
SLI v1: early(0~2) / mid(3~5) / late(6~12) → 비율 기반 (late/early ≥ 0.6)
SLI v2: early(0~2) / mid(3~5) / late1(6~8) / late2(9~12) → 로그 차이 기반
```

> **왜 4구간인가?**
> 6\~12개월을 하나로 묶으면, "6개월 차에는 유지되지만 10개월 이후 재상승"하는 **후기 가속** 패턴을 포착할 수 없습니다. late1(6\~8)과 late2(9~12)를 분리해서 **"후기에 다시 살아나는 제품"** 을 식별합니다.

### ② 비대칭 기울기 (Directional Slope)

기존: `slope = polyfit` → 상승이든 하락이든 절대값으로 패널티
SLI_v2: **하락만 패널티**, 상승은 감점 안 함

```
slope = -5.0 (하락) → slope_neg = 5.0 (패널티 부과)
slope = +3.0 (상승) → slope_neg = 0.0 (감점 없음)
```

> **왜 비대칭인가?**
> 상승 추세는 "성장"이므로 연착륙에 부정적이지 않습니다. 기존 방식에서는 성장하는 제품도 기울기 절대값이 커서 불이익을 받았습니다. SLI_v2는 **하락만 위험 신호**로 보고, 상승은 자유롭게 허용합니다.

### ③ 후기 변동성 (Late Volatility CV)

후기 구간(6개월+)에서의 **변동계수(CV = 표준편차 / 평균)**  를 측정합니다.

```
제품 A: 후기 리뷰 [50, 55, 48, 52] → CV = 0.05 (안정적)
제품 B: 후기 리뷰 [80, 10, 90, 5]  → CV = 0.95 (불안정)
```

> **왜 후기만 보나?**
> 초기(0~5개월)는 프로모션, 품절, 바이럴 등으로 자연스럽게 변동이 큽니다. 연착륙의 핵심은 **"후기에 안정적으로 유지되는가"** 이므로, 후기 데이터에서만 변동성을 측정합니다.

### ④ RobustScaler + 가중합

6개 컴포넌트를 **RobustScaler**(중앙값 기준, 이상치에 강건)로 표준화한 후 가중합합니다.

| 컴포넌트              | 가중치          | 의미               |
| --------------------- | --------------- | ------------------ |
| `mid_minus_early`   | **+0.20** | 초기→중기 유지    |
| `late1_minus_mid`   | **+0.25** | 중기→후기초 유지  |
| `late2_minus_late1` | **+0.35** | 후기 가속 (핵심)   |
| `log_total_reviews` | **+0.15** | 규모 기여도        |
| `slope_neg`         | **-0.05** | 하락 패널티        |
| `late_vol_cv`       | **-0.05** | 후기 변동성 패널티 |

> **왜 후기 가속(0.35)이 가장 높은가?**
> 프로젝트의 연착륙 정의가 "초기 붐 이후에도 무너지지 않고 **후기에 재상승하는 상품**"이기 때문입니다. late2_minus_late1이 양수라면 "9~12개월 차에 다시 올라가는 제품"을 의미합니다.

### ⑤ 전문가 가중치란?

위 표의 가중치(0.20 / 0.25 / 0.35 / 0.15 / -0.05 / -0.05)는 **수학적 최적화가 아니라, 팀원(영호님)이 화장품 시장 경험과 데이터 패턴 관찰을 바탕으로 직접 설정한 값**입니다. 이를 본 리포트에서 **"전문가 가중치"** 라고 부릅니다.

예를 들어 "후기에 다시 살아나는 게 연착륙의 핵심이니까 `late2_minus_late1`에 가장 높은 0.35를 주자"는 식의 **사람의 판단**으로 정해진 것입니다.

> **"그럼 이 값이 정말 맞는 걸까?"** 라는 의문이 자연스럽게 생깁니다. 이에 대한 답은 **§10 부록**에서 Grid Search 927개 조합을 컴퓨터로 전수 탐색하여, 전문가 가중치가 최적값과 단 2개(1.3%) 차이밖에 나지 않음을 데이터로 검증합니다.

## 2. 왜 이 RQ를 분석하는가?

### 비즈니스 배경

- **현상**: 기존 SLI 통합분석은 규칙기반으로 3구간 단순 비율(late/early ≥ 0.6)을 사용. 영호님이 SLI_v2.ipynb에서 4구간 유지력 + 비대칭 기울기 기반의 개선 로직을 개발 완료.
- **질문**: SLI_v2를 통합분석 파이프라인에 이식하면 연착륙 판별이 개선되는가?
- **기대 효과**: (1) 규칙기반 판별의 정밀도 향상, (2) ML 모델에 도메인 지식 피처 추가로 예측력 강화

### 연구 질문 정의

> **RQ :** SLI_v2(4구간 유지력 + 비대칭 기울기) 로직으로 규칙기반 모듈을 교체하고, SLI_v2 컴포넌트를 ML 피처에 추가하면, 연착륙 식별의 정확도와 신뢰도가 개선되는가?

>   - **초기집중형:** 첫 1~2개월에만 리뷰가 쏠리고 이후 거의 없는 패턴 → 비연착륙
> * **핵심:** 후기상승형 + 안정유지형이 연착륙 후보이며, 이 그래프에서 선들이 뒤쪽(오른쪽)에서 올라가거나 유지되는 유형이 "좋은 제품"입니다.

### 방법론 ② Kaplan-Meier 생존곡선

![Kaplan-Meier 생존곡선](../../02_outputs/01_figures/SLI/02_survival_curves.png)

> **해석:**
>
> * **이 그래프가 보여주는 것:** 제품이 시간이 지나면서 얼마나 "살아남는지"를 보여주는 **생존 곡선**입니다. 의학에서 환자의 생존율을 추적하는 방법을 제품에 적용한 것입니다.
> * **X축:** 피크(가장 리뷰가 많았던 달) 이후 경과 월수
> * **Y축:** 생존 확률 (= 아직 리뷰가 활발하게 달리고 있는 제품의 비율). 1.0이면 전부 살아있고, 0.0이면 전부 사망.
> * **"사망" 기준:** 가장 리뷰가 많았던 달 대비 **30% 이하**로 **2개월 연속** 떨어지면 "이 제품은 시장에서 사라졌다"고 판정합니다.
> * **곡선 읽는 법:** 곡선이 **천천히 내려갈수록** 오래 버티는 제품이 많다는 뜻입니다. 곡선이 급격히 뚝 떨어지는 구간은 "그 시점에 많은 제품이 한꺼번에 사망했다"는 의미입니다.

## 5. Step 1: SLI_v2 규칙기반 교체

### 무엇을 변경했는가?

기존 `rule_based_soft_landing()` 함수를 4개의 SLI_v2 컴포넌트 함수로 교체했습니다.

**기존 (3구간 단순 비율):**

```python
early = counts[:3].mean()
mid = counts[3:6].mean()
late = counts[6:].mean()
retention_ok = (late/early >= 0.6) and (mid/early >= 0.7)
slope = np.polyfit(range(len(counts)), counts, 1)[0]
slope_ok = slope > -0.5
```

**변경 후 (SLI_v2 — 4구간 + 비대칭 기울기):**

```python
# 4구간 중앙값(median) + log1p 차이
mid_minus_early   = log1p(mid_median)   - log1p(early_median)
late1_minus_mid   = log1p(late1_median) - log1p(mid_median)
late2_minus_late1 = log1p(late2_median) - log1p(late1_median)  # ★ 후기 가속

# 비대칭 기울기 (하락만 패널티)
slope_neg = -slope if slope < 0 else 0.0

# 후기 변동성 (6개월+ CV)
late_vol_cv = std(late_counts) / mean(late_counts)

# RobustScaler 표준화 + 가중합 → SLI_v2 > 0이면 연착륙
```

### SLI_v2 규칙기반 결과

| 항목               | 기존 (3구간)  | **SLI_v2 (4구간)** | 변화           |
| ------------------ | ------------- | ------------------------ | -------------- |
| 규칙기반 연착륙 수 | 218개 (30.9%) | **284개 (40.2%)**  | +66개 (+30.3%) |
| SLI_v2 중앙값      | —            | 0.0315                   | —             |
| SLI_v2 > 0 비율    | —            | 40.2%                    | —             |

> **해석:** SLI_v2는 기존보다 66개 더 많은 상품을 규칙기반 연착륙으로 판정했습니다. 이는 SLI_v2가 **후기 가속(late2_minus_late1)** 패턴을 추가로 포착하기 때문입니다. 기존 3구간 규칙에서는 "late 전체 평균"이 낮아서 탈락했지만, 4구간으로 나누면 "9~12개월에 재상승"하는 제품이 추가로 포착됩니다.

![SLI_v2 유지력 분포](../../02_outputs/01_figures/SLI/08_03_retention_distribution.png)

> **해석:**
>
> * **X축 (잔존율):** 제품의 출시 후 최대 리뷰 수(피크) 대비 최근 3개월간의 평균 리뷰 수 비율입니다. 1.0에 가까울수록 피크 때의 인기를 현재까지 잘 유지하고 있음을 의미합니다.
> * SL 상품의 중앙값(0.371)**은** Non-SL 상품(0.175)보다 약 2배 이상 높습니다. 이는 연착륙 상품이 초기 붐이 지나간 후에도 피크 대비 약 37% 이상의 리뷰를 꾸준히 생성하며 시장에 성공적으로 안착했음을 입증합니다.         그래프 중앙의 **연두색 음영 구역(30~50%)** 은 SL 상품들이 가장 밀집된 구간입니다. 우리 프로젝트의 SLI 로직에서 연착륙을 판별하는 핵심 기준선이 이 부근에서 형성됩니다. 반면 Non-SL 상품은 대부분 20% 미만(빨간색 점선 왼쪽)에 몰려 있어 극명한 대조를 이룹니다.

### Pseudo Label 변화 (3/3 투표)

| -------------------------- | ----- | ------------------------ |
| 만장일치(3/3) Pseudo Label | 152개 | **171개**          |
| 비율                       | 21.5% | **24.2%**          |

> Pseudo Label이 152→171개로 증가. 규칙기반이 더 관대해지면서, DTW + 생존 + SLI_v2 모두 동의하는 상품이 늘었습니다.

## 6. Step 2: SLI_v2 컴포넌트 ML 피처 추가

### 추가된 SLI_v2 도메인 피처 (6개)

기존 시계열 피처(14개)에 SLI_v2 컴포넌트 6개를 추가하여 총 **21개** 시계열 피처로 확장했습니다.

| 피처                  | 의미                         | 기존 피처와의 차이               |
| --------------------- | ---------------------------- | -------------------------------- |
| `sli_v2_score`      | SLI_v2 최종 점수             | 6개 컴포넌트의 가중합            |
| `mid_minus_early`   | 초기→중기 유지 (log1p 차이) | 기존 `ts_retention_mid`는 비율 |
| `late1_minus_mid`   | 중기→후기초 유지            | 기존에는 없음 (6~8개월 분리)     |
| `late2_minus_late1` | **후기 가속**          | 기존에는 없음 (9~12개월 분리)    |
| `slope_neg`         | 하락 패널티                  | 기존 `ts_slope`는 양방향       |
| `late_vol_cv`       | 후기 변동성                  | 기존 `ts_cv`는 전체 기간       |

### ML 모델 성능

| 지표           | 기존   | **SLI_v2 통합 후** | 변화   |
| -------------- | ------ | ------------------------ | ------ |
| OOF F1         | 0.8957 | **0.8705**         | -0.025 |
| OOF AUC        | 0.9851 | **0.9827**         | -0.002 |
| Precision (SL) | 0.84   | **0.82**           | -0.02  |
| Recall (SL)    | 0.96   | **0.92**           | -0.04  |
| Train-Val Gap  | 0.069  | **0.132**          | +0.063 |

> **해석:** ML 성능이 소폭 하락했습니다 (F1: 0.90 → 0.87). 이는 Pseudo Label이 152→171개로 증가하면서 학습 데이터의 양성 경계가 넓어진 영향입니다. AUC 0.98은 여전히 우수한 수준이며, Gap 0.13도 허용 범위입니다. **성능 하락보다 피처 기여도가 더 중요한 포인트**입니다.

![LightGBM 혼동행렬](../../02_outputs/01_figures/SLI/04_ml_confusion_matrix.png)

> **해석:**
>
> * - **좌상 (True Positive):** 모델이 "연착륙"이라 예측했고, 실제로도 연착륙 → 정답 (맞춤)
>   - **우상 (False Positive):** 모델이 "연착륙"이라 예측했지만, 실제로는 비연착륙 → 오탐 (빗나감)
>   - **좌하 (False Negative):** 모델이 "비연착륙"이라 예측했지만, 실제로는 연착륙 → 놓침 (가장 아쉬운 실수)
>   - **우하 (True Negative):** 모델이 "비연착륙"이라 예측했고, 실제로도 비연착륙 → 정답 (맞춤)
> * **핵심 수치:**
>   - **Recall 92%:** 진짜 연착륙 제품 100개가 있으면 그 중 92개를 잡아냅니다. 8개만 놓칩니다.
>   - **Precision 82%:** 모델이 "이건 연착륙이야!"라고 예측한 것 중 82%가 실제로 연착륙입니다. 18%는 오탐(잘못된 예측)입니다.
> * **비즈니스 의미:** Recall이 높다는 것은 "효자 상품을 거의 놓치지 않는다"는 뜻이므로, 상품 기획 의사결정에 신뢰할 수 있는 수준입니다.

## 9. 결론 및 실행 제언

### 핵심 인사이트

1. **SLI_v2 규칙기반은 기존 대비 더 관대하지만 합리적** — 284개(+30.3%)로 후기 가속 패턴을 추가 포착. 다만 최종 만장일치에서는 158개(+8.2%)로 수렴하여, 4개 방법론 합의 구조가 **자동 필터링** 역할을 수행

   - SLI_v2 중앙값 0.0315로, threshold=0 기준이 적절
2. **SLI_v2 컴포넌트가 ML에 유의미하게 기여** — `slope_neg`(6위, 0.1474)과 `late_vol_cv`(7위, 0.1457)가 ABSA 피처보다 높은 SHAP 중요도

   - "하락 방향성"과 "후기 안정성"이 연착륙 판별의 핵심 보조 신호
3. **스킨케어 후기 재구매 패턴이 SLI_v2에서 더 잘 포착** — 스킨케어 비율 65.8% → 68.4%, 본셉·바세린 신규 진입

   - 일상 소모품의 9~12개월 재구매 사이클이 late2_minus_late1에 반영
4. **ML 성능은 소폭 하락하나 허용 범위** — F1 0.90 → 0.87, AUC 0.99 → 0.98

   - Pseudo Label 확대(152→171)에 의한 자연스러운 변동

## 10. 부록: SLI_v2 가중치 민감도 분석

### 10-1. 1차원 민감도 분석

6개 가중치를 각각 독립적으로 ±50% 범위에서 변화시키며, 나머지는 전문가 가중치로 고정한 상태에서 만장일치(4/4) 수와 3표 이상 수의 변화를 측정했습니다.

![1차원 민감도 분석](../../02_outputs/01_figures/SLI/09_01_sensitivity_1d.png)

> **해석:**
>
> * **이 그래프가 보여주는 것:** "가중치 하나를 바꾸면 결과가 얼마나 달라질까?"를 테스트한 결과입니다. 6개 가중치를 각각 **원래 값의 ±50% 범위**에서 변화시키며, 나머지 5개는 고정한 상태에서 만장일치 수의 변화를 관찰했습니다.
> * **X축:** 가중치 값 (원래 값을 중심으로 ±50% 변화)
> * **Y축:** 만장일치(4/4) 수 — 4개 방법론 모두 연착륙이라 동의한 제품 수
> * **읽는 법:** 선이 **수평에 가까울수록** 해당 가중치를 바꿔도 결과가 거의 변하지 않는다는 뜻입니다(= 강건함). 선이 기울어질수록 해당 가중치에 결과가 민감하다는 뜻입니다.
> * **핵심 발견:**
>   - 6개 가중치 모두에서 만장일치 수가 **±5개 이내**로 안정적입니다.
>   - **`late2_minus_late1`(후기 가속)** 과 **`late1_minus_mid`(중기→후기 유지)** 에서 변동이 가장 큽니다 → 이 두 가중치가 SLI_v2의 핵심 파라미터입니다.
>   - **`slope_neg`과 `late_vol_cv`(패널티 가중치)** 는 변화에 둔감합니다 → 이 값을 조금 바꿔도 결과에 거의 영향 없어 강건합니다.
> * **의미:** 전문가 가중치를 약간 다르게 설정했더라도 최종 결과는 크게 달라지지 않았을 것입니다.

> * **비즈니스 시사점:** 다이소 입점 시 순한 수분 베이스 스킨케어를 우선 선별하면 연착륙 확률이 높아집니다.

### 12-2. 성분 효능(Effect) 분포 비교

>   - **Color(-22.2%p):** 발색 — 색을 내는 역할의 성분. 색조 화장품(립, 아이섀도)에 집중됩니다.
>   - **Texture(-7.3%p):** 텍스처 — 제품의 질감을 만드는 성분. 파운데이션, 프라이머 등에 많습니다.
> * **Type 분석과의 연결:** Type에서 "Colorant가 비연착륙에 많다"고 나왔는데, Effect에서도 "Color 효능이 비연착륙에 많다"고 나와 **교차 검증**이 됩니다. 색조 화장품이 연착륙에 불리하다는 결론이 두 가지 분석에서 동일하게 나타납니다.

### 12-3. Type × Effect 히트맵

![Type×Effect 히트맵](../../02_outputs/01_figures/SLI/10_06_type_effect_heatmap.png)

> **해석:**
>
> * **이 그래프가 보여주는 것:** 성분 계열(Type)과 효능(Effect)을 **교차 조합**하여, 어떤 "계열 × 효능" 조합이 연착륙 제품에 특히 많은지 히트맵으로 보여줍니다. 앞선 두 분석을 합친 심화 분석입니다.
> * **X축:** 성분 효능 (Effect) — Preservative, Base, Color, Texture 등
> * **Y축:** 성분 계열 (Type) — Ether, Paraben, Colorant, Acid 등
> * **색상:** 빨간색/따뜻한 색 = 연착륙 제품에 더 많은 조합, 파란색/차가운 색 = 비연착륙 제품에 더 많은 조합
> * **Lift란?** "연착륙 제품에서 해당 조합이 비연착륙 대비 몇 배 더 자주 나타나는가"를 나타내는 수치입니다. Lift 3.0이면 3배, Lift 0.5면 절반 수준.
> * **핵심 발견:**
>   - **Ether × Base (Lift 3.0):** 에테르 계열 기제 조합 — 로션, 크림의 기본 골격 성분. 연착륙 제품에서 3배 더 자주 출현합니다.
>   - **Paraben × Preservative (Lift 3.0):** 파라벤 방부 조합 — 수분 함량 높은 스킨케어 제품의 필수 보존 처방. 역시 3배 더 자주 출현합니다.
>   - 반대로 **Colorant × Color** 조합은 비연착륙 쪽에 치우쳐 있습니다.
> * **비즈니스 시사점:** 연착륙 제품의 "성분 DNA"는 **"에테르 기제 + 파라벤 방부"** 라는 안정적인 기초 스킨케어 처방으로 요약됩니다. B2B 입점 심사 시 이 성분 조합 패턴을 기준으로 활용할 수 있습니다.
