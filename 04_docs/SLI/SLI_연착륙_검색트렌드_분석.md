> **데이터 수집 방법:**
> 네이버 검색광고 API를 활용하여 제품명 + 브랜드명 조합 키워드의 블로그·쇼핑·뉴스 검색량을 수집 (수집일: 2026-02-27)

  - 블로그: 2,358,870건 (92.3%)

#### 검색량과 연착륙 관계

**가설:** 검색량이 높을수록 제품 인지도가 높아 리뷰 유입이 많고, 연착륙에 유리할 것

**검증 필요 사항:**

- 검색량과 리뷰 수의 상관관계 (Pearson r)
- 검색량과 참여도 점수의 상관관계
- 검색량 상위 25% vs 하위 25% 그룹 간 연착륙 비율 차이

### 축5-2: 검색 패턴 심층 분석

#### 무엇을 보는가?

제품별 검색 키워드(브랜드명, "다이소", "후기", "리뷰" 포함 여부)와 검색 채널(블로그/쇼핑/뉴스)의 패턴을 분석하여, **어떤 키워드와 채널이 효과적인지** 파악합니다.

#### (1) 키워드 패턴 분석

**"다이소" 키워드 포함 vs 미포함:**

| 키워드 패턴      | 평균 총 검색량 | 중앙값 | 블로그 평균 | 쇼핑 평균 |
| ---------------- | -------------- | ------ | ----------- | --------- |
| 다이소 **미포함** | 9,753          | 1,722  | 9,128       | 593       |
| 다이소 **포함**   | 3,424          | 1,041  | 3,385       | 26        |

**인사이트:**

- **"다이소" 키워드 포함 시 검색량이 오히려 낮음** (3,424 vs 9,753)
- **이유 추정:**
  - 더마블록, 바세린 같은 **브랜드명 자체로 검색**되는 제품이 고검색량
  - "다이소 + 제품명"은 **다이소 자체 브랜드**(딥 클렌징 폼 등) 검색에만 사용
  - **브랜드 파워 = 다이소 키워드 불필요**
- **시사점:** 브랜드명이 강한 제품 입점 시 "다이소"를 강조할 필요 없음

**"후기" vs "리뷰" 키워드 비교:**

| 키워드 | 평균 검색량 | 중앙값 | 최대값  |
| ------ | ----------- | ------ | ------- |
| 후기   | 8,462       | 1,745  | 138,135 |
| 리뷰   | 5,663       | 1,607  | 68,263  |

**인사이트:**

- **"후기" 키워드가 "리뷰"보다 평균 50% 높음** (8,462 vs 5,663)
- **이유:**
  - 한국 사용자는 "후기"를 더 자주 검색 (네이티브 표현 선호)
  - 블로그 포스팅 제목에 "후기"가 더 많이 사용됨
- **시사점:** 리뷰 이벤트 안내 시 **"사용후기 작성"** 표현 사용 권장

## 종합 인사이트

### 1. 블로그가 핵심 채널 (92.3%)
- 리뷰·사용후기 중심 검색
- **액션:** 체험단 확대, 블로그 SEO 강화

### 2. 브랜드 파워가 검색량 좌우
- 더마블록, 바세린 등 브랜드명만으로 검색
- **액션:** 강력한 브랜드 입점 우선순위

### 3. 다이소 자체 브랜드는 쇼핑 검색 강함
- 가격 비교 목적
- **액션:** 쇼핑몰 최적화, 가격 경쟁력

### 4. 키워드 전략
- "후기" > "리뷰" (1.5배)
- 브랜드명 강하면 "다이소" 불필요
- **액션:** "사용후기 작성" 표현 사용

### 5. 카테고리별 차별화
- 자외선차단제: 블로그 집중
- 클렌징/아이메이크업: 쇼핑 강화
- **액션:** 카테고리별 채널 전략 수립

## 한계 및 향후 과제

### 현재 한계

1. **SL 제품만 수집**
   - Non-SL 제품과 비교 불가
   - 검색량과 연착륙 인과관계 검증 불가

2. **시점 데이터 (Snapshot)**
   - 검색량 변화 추이 미파악
   - 계절성, 트렌드 변화 반영 불가

3. **키워드 한계**
   - 제품명 + 브랜드명 조합만 수집
   - 카테고리 키워드("선크림 추천") 미수집

### 향후 과제

1. **Non-SL 제품 검색량 수집**
   - SL vs Non-SL 통계 검정
   - 검색량과 연착륙 인과관계 분석

2. **시계열 검색 트렌드 수집**
   - 네이버 DataLab API 활용
   - 검색량 변화 패턴과 연착륙 관계 분석

3. **카테고리 키워드 확대**
   - "선크림 추천", "클렌징폼 순위" 등 범용 키워드
   - 제품명 외 검색 유입 경로 파악

4. **검색량과 실제 판매 연계**
   - 검색량 → 리뷰 수 → 판매량 경로 분석
   - ROI 기반 마케팅 최적화
