## 1. 모델 아키텍처

**"KcELECTRA + Multi-task 구조로, 하나의 리뷰에서 8개 aspect의 감성을 동시에 예측합니다."**

KcELECTRA-base(beomi/KcELECTRA-base, 768차원)의 [CLS] 토큰 임베딩 위에 두 개의 분류 헤드를 병렬로 배치한 Multi-task 구조입니다.

- **Sentiment Head**: 리뷰 전체의 감성 (positive / neutral / negative) → [B, 3]
- **Aspect-Sentiment Head**: 8개 aspect 각각에 대해 (none / positive / neutral / negative) 4-class 분류 → [B, 8, 4]

여기서 `none`은 "해당 aspect를 언급하지 않음"을 의미합니다. 예를 들어 "발림성 좋아요"라는 리뷰는 사용감/성능=positive, 나머지 7개=none으로 예측됩니다.

Loss 함수는 **Masked CrossEntropyLoss**로, 라벨이 존재하는 셀만 학습에 참여합니다. 클래스 불균형 대응을 위해 class weight를 적용했으며, 특히 neutral 클래스의 weight가 8.06(Stage 2)→6.82(Stage 4)로 보정되었습니다.

## 4. 5-Stage 개선 여정

**"한 번에 완성된 모델이 아닙니다. 5단계에 걸쳐 체계적으로 개선했습니다."**

### Stage 1 → Stage 2: 구조 개편

- **문제**: 11개 aspect 중 미분류(30.8%)가 지배적, 과다 검출 심각
- **조치**: 8개 aspect로 축소, 디자인 Negative Sampling(+2,500건), F0.5(precision 가중) 메트릭으로 threshold 튜닝
- **결과**: Detection Precision 0.61 달성, 그러나 디자인 Precision 0.17로 여전히 취약

### Stage 2 → Stage 3A: 후처리 튜닝 (재학습 없음)

모델 자체를 건드리지 않고 후처리 규칙만으로 성능을 끌어올린 단계입니다.

**3가지 핵심 변경:**

1. **Design Rule Override**: 디자인 aspect를 모델 예측 대신 키워드 규칙(디자인, 패키지, 예쁘 등)으로 판단. 모델의 디자인 Precision 0.17 문제를 근본적으로 해결
2. **사용감/성능 None-threshold**: 0.10 → 0.03으로 하향. 직관과 반대로, threshold를 낮추면 P(none) >= θ 조건이 더 쉽게 충족되어 **검출이 줄어드는** 구조. 사용감 과검출을 억제하는 핵심 발견
3. **Polar Threshold**: 0.55 → 0.50으로 하향. max(P(pos), P(neg)) < 0.50이면 neutral로 분류

**결과**: Detection Precision **0.61 → 0.67** (+6pp), GO/NO-GO 4개 기준 중 4개 달성. 이 시점에서 **첫 번째 GO 판정**을 내리고 323K 전체 추론 실행.

### Stage 3A → 전체 추론 + QC

323,114건 전체 리뷰에 대해 추론을 실행했습니다.

- **소요 시간**: 62.8분 (85.8 reviews/sec, GPU)
- **전체 감성 분포**: 긍정 66.5% / 중립 29.1% / 부정 4.4%
- **미분류율**: 28.7% (8개 aspect 전부 none)

**v1 → v2 키워드 게이트 개선**: 가격/가성비, 용량/휴대, 재질/냄새 3개 aspect에 Keyword Gate OFF 규칙을 추가하여, 관련 키워드가 없는 리뷰에서의 False Positive를 억제. 재구매 aspect에는 반대로 "재구매" 키워드 포함 시 Force-ON 규칙 적용.

### Stage 4: Neutral 보강 재학습

**문제**: 전체 추론 EDA에서 neutral이 aspect-level에서 극히 적게 예측됨. QC 분석 결과, 학습 데이터의 neutral이 전체 mask=1 셀의 **2.5%**(1,356건)에 불과한 것이 근본 원인으로 확정.

**보충 데이터 설계:**

| 소스 | 건수 | 목적 |
|------|------|------|
| Neutral 증강 (GPT-4o) | 750건 | neutral 절대 샘플 확보 |
| QC 교정 | 443건 | 오류 패턴 7가지 교정 |
| 골든셋 활용 | 877건 | 사람 검수 고품질 데이터 |
| **총 보충** | **2,070건** | |

학습 데이터: 11,679 → **13,749건**으로 확대. Neutral class weight 8.06 → 6.82로 감소하여 모델이 neutral을 더 적극 예측할 환경 확보.

### Stage 5: 전략 A/B/C 실험 → Pragmatic GO

Stage 4 모델을 기반으로 3가지 고도화 전략을 실험했습니다.

| 전략 | 방법 | 핵심 결과 |
|------|------|-----------|
| **A: Warm-start** | S4 checkpoint → 미세 조정 | Det.P **0.8290** (역대 최고), Gap **-9.6pp** (역대 최소) |
| B: Encoder Freeze | Phase 2에서 head-only 재학습 | Det.R 0.74~0.81 (대폭 향상), 사용감 과검출 +16.9~34.1pp |
| C: Focal Loss | hard sample 집중 학습 | Sent.F1 0.4270, Neu.R 0.3276 (역대 최고) |

**전 모델 비교 (11개 config):**

| 모델 | Det.P | Sent.F1 | Neu.R | GO |
|------|-------|---------|-------|----|
| Stage 2+3A (기존) | 0.8203 | 0.3669 | 0.1379 | 2/4 |
| S4 (scratch) | 0.8367 | 0.3480 | 0.1552 | 2/4 |
| **S4B (Warm-start)** | **0.8290** | **0.3889** | **0.2759** | **3/4** |
| P3 best (Focal) | 0.7786 | 0.4270 | 0.3276 | 3/4 |

**Pragmatic GO 판정 근거:**

4개 KPI 중 3개 달성, 미달 지표(Sent.F1 0.3889, 목표 0.43)는 9.5% 부족이나:

1. **통계적**: 골든셋 266건에서 1~2건 판정 변화로 0.43 도달 가능한 수준
2. **비즈니스**: SLI(연착륙 상품 발굴)에 가장 중요한 Detection Precision(0.8290)과 분포 정합성(-9.6pp)에서 S4B가 압도적
3. **실전 배포**: 323K건 집계 분석에서 개별 셀 오류는 대수의 법칙으로 희석되지만, 분포 왜곡은 집계할수록 증폭됨. S4B의 보수적 과소검출(-9.6pp)이 P3의 과다검출(+18.8pp)보다 안전

**최종 배포 모델: S4B (Warm-start)**

## 5. 후처리 파이프라인 (Stage 3A-v2)

**"모델 예측 → 5단계 후처리를 거쳐 최종 결과를 산출합니다."**

```
모델 raw 출력 (8 aspect × 4-class 확률)
    │
    ▼
[1] Per-aspect None Threshold
    P(none) >= θ_aspect → none으로 강제
    (aspect별 개별 threshold, F0.5 기준 튜닝)
    │
    ▼
[2] Design Rule Override
    디자인 aspect → 키워드 규칙으로 판단
    ("디자인", "패키지", "예쁘", "귀엽" 등)
    │
    ▼
[3] Keyword Gate OFF
    가격/가성비, 재질/냄새, 용량/휴대:
    관련 키워드 없으면 none으로 억제
    │
    ▼
[4] Keyword Force ON
    재구매: "재구매" 키워드 포함 시 강제 활성화
    │
    ▼
[5] Polar Threshold
    max(P(pos), P(neg)) < 0.50 → neutral
```

이 5단계 후처리는 Stage 3A에서 설계되어 Stage 5까지 동일하게 적용됩니다. 모델이 바뀌어도 후처리 규칙은 재사용 가능한 독립 모듈로 운영됩니다.

## 발표 시 예상 질문 대비

### Q. "왜 KcELECTRA인가? BERT나 다른 모델은?"
KcELECTRA는 한국어 댓글/리뷰 도메인에 특화된 사전학습 모델로, 일반 BERT 대비 한국어 감성 분석에서 높은 성능을 보입니다. 768차원 임베딩으로 파라미터 효율성이 높아 GPU 메모리 제약 내에서 Multi-task 학습이 가능했습니다.

### Q. "Pragmatic GO라면 완벽하지 않다는 건데?"
맞습니다. Sent.F1이 0.3889로 목표 0.43에 9.5% 미달입니다. 그러나 이 프로젝트의 목적은 개별 리뷰의 정밀 분류가 아니라, 323K건의 **집계 분석**을 통한 연착륙 상품 발굴입니다. 집계 시 개별 오류는 대수의 법칙으로 희석되며, 더 중요한 것은 분포 왜곡이 없는 것입니다. S4B의 분포 gap -9.6pp는 전 모델 중 가장 작아, 집계 분석에 최적입니다.

### Q. "미분류 28.7%가 너무 높은 것 아닌가?"
미분류는 8개 aspect 전부 none인 리뷰로, 실제로 특정 aspect에 대한 평가가 없는 경우가 대부분입니다. "선물용", "아직 안 써봄", "좋아요~" 등 단순 표현이 여기에 해당합니다. 이는 모델의 한계가 아니라 리뷰 데이터 자체의 특성으로, 무리하게 aspect를 할당하면 오히려 False Positive가 증가합니다.

### Q. "후처리가 많으면 모델 성능이 의미 없는 것 아닌가?"
후처리는 모델의 약점을 보완하는 안전장치 역할입니다. 예를 들어 디자인 aspect는 학습 데이터가 부족해 모델 Precision이 0.17이었지만, 키워드 규칙으로 대체하여 실용적 정확도를 확보했습니다. 모델과 규칙이 각자의 강점을 담당하는 하이브리드 접근입니다.

### Q. "GPT-4o가 더 정확하면 그냥 GPT로 추론하면 안 되나?"
비용 문제입니다. 323K건 × $0.00434 = $1,400이며, 매월 증분 크롤링 시마다 추가 비용이 발생합니다. KcELECTRA는 초기 $99로 학습 후 무한 추론이 가능하고, 후처리 파이프라인으로 도메인 특화 보정까지 적용 가능합니다. 장기 운영 관점에서 KcELECTRA가 압도적으로 유리합니다.
