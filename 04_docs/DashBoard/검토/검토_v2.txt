1) 미반영 독립변수 문제 
보고서에서 "주 성분 적합성, 성분 심플리시티 두 독립변수가 평가 함수 내에 생성 로직이 없어 누락됨"이라고 적혀 있습니다. 그런데 기존 시뮬레이터의 스코어카드에서 축4(성분 심플리시티)와 축6(주 성분 적합성)은 각각 10점, 15점으로 전체 100점 중 25%를 차지합니다. 이 두 축이 Grid에서 빠져있으면 시뮬레이션 결과의 신뢰도가 근본적으로 훼손됩니다..ㅠㅠ

2) Grid 데이터 볼륨 및 현실성 필터 부재
변수 범위를 보면 가격 5종 x 성분 수 16종(1~80, 5단위) x 저자극 4종 x 기능성 2종 x 카테고리 14종 x 브랜드 영향 8종 x 수분 비율 10종 = 약 573,440행입니다.
 보고서에서도 "비현실적 조합이 포함"됨을 인정했는데, 예를 들어 성분 1개이면서 기능성 등록 제품이라든가, 가격 500원에 성분 80개인 조합은 물리적으로 불가능합니다.
 이런 조합을 사전 필터링하는 로직이 없으면 Tableau에서 사용자가 비현실적 시나리오를 선택했을 때 오해를 유발합니다. Grid 생성 단계에서 제약 조건(예: 성분 수 ≤ 가격대별 상한)을 걸면 좋을 것 같습니다
