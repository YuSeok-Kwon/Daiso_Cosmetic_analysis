## 1. 분석 개요

### 1.1 목적

실제 검색 결과 건수를 통해 시장 규모와 채널별 경쟁도 파악

### 1.2 방법론

- **API**: 네이버 검색 API (blog/shop/news)
- **지표**: 실제 검색 결과 총 건수 (total field)
- **키워드 생성 규칙**:
  - 다이소 자체 브랜드: "다이소 {제품}", "{제품}", "다이소 {제품} 후기"
  - 일반 브랜드: "{브랜드} {제품}", "다이소 {브랜드} {제품}", "{브랜드} {제품} 후기/리뷰"
- **제품별 집계**: 최대 검색량을 보인 키워드 기준

### 1.3 DataLab 트렌드 분석과의 차이

| 항목 | DataLab | 검색 API |
|------|---------|----------|
| 지표 | 상대 검색량 (0-100) | 실제 검색 결과 건수 |
| 활용 | 트렌드 변화 추적 | 시장 규모 및 경쟁도 파악 |
| 장점 | 시계열 변화 추적 | 절대적 시장 크기 측정 |
| 한계 | 절대 규모 불명 | 트렌드 변화 추적 불가 |

**통합 활용 전략**:
- DataLab: 검색량 증가 추세 → 기회 제품 발굴
- 검색 API: 시장 규모 → 투자 우선순위 결정

## 11. 한계 및 향후 과제

### 11.1 분석의 한계

1. **검색량 ≠ 판매량**
   - 검색량이 높아도 실제 구매로 이어지는지 불명
   - 리뷰 데이터와 교차 분석 필요

2. **키워드 최적화 편차**
   - 일부 제품은 키워드 설정 실패로 검색량 과소평가 가능
   - 실제 소비자 검색어 로그 분석 필요

3. **시계열 변화 미반영**
   - 단일 시점 스냅샷 → 트렌드 변화 추적 불가
   - DataLab 트렌드 분석과 통합 필요

### 11.2 향후 과제

1. **DataLab + 검색 API 통합 분석**
   - DataLab: 트렌드 변화 추적
   - 검색 API: 시장 규모 측정
   - 통합: 기회 제품 발굴 + 투자 우선순위 결정

2. **리뷰 데이터와 교차 검증**
   - 검색량 높은 제품 vs 리뷰 평점 높은 제품 비교
   - 갭 분석 → 마케팅 기회 발굴

3. **실제 판매 데이터 연계**
   - 검색량 vs 판매량 상관관계 분석
   - ROI 기반 마케팅 채널 최적화
