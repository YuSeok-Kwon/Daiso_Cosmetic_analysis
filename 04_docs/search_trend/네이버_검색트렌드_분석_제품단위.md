# 네이버 검색 트렌드 분석 - engagement_score TOP 50 제품

> 분석일: 2026-02-25 | API: 네이버 DataLab 검색어 트렌드 | 대상: 다이소 뷰티 engagement_score 상위 50개 제품

---

## 1. 분석 개요

### 1.1 목적

다이소 뷰티 engagement_score TOP 50 **개별 제품(상품명)**의 네이버 검색 트렌드를 분석하여, 브랜드 단위 분석에서는 보이지 않았던 **제품 레벨의 검색 수요와 시계열 패턴**을 파악한다.

### 1.2 방법론

| 항목        | 내용                                                                              |
| ----------- | --------------------------------------------------------------------------------- |
| API         | 네이버 DataLab 검색어 트렌드 (`/v1/datalab/search`)                             |
| 키워드      | 제품당 최대 20개 OR 조합 (풀네임 5 + 축약 4 + 의도 6 + 속성 5)                    |
| 지표        | **상대 검색량 ratio** (배치 내 최고값=100 기준 상대비율)                    |
| 기간        | 2024-01-01 ~ 2026-01-31 (월 단위)                                                 |
| 세분화      | 성별(남/여), 연령대(10대~60대), 기기(PC/모바일)                                   |
| 앵커        | engagement 1위(VT 리들샷 100)를**단일 앵커**로 사용 — 세그먼트별 동일 기준 |
| 총 API 호출 | 274회 (키 2개 라운드로빈: 137/137)                                                |

### 1.3 핵심 용어

- **ratio**: 네이버 DataLab이 제공하는 상대 검색량. 배치(5그룹) 내에서만 직접 비교 가능
- **앵커 정규화**: 모든 배치에 engagement 1위(VT 리들샷 100)를 포함시켜, 앵커=100 기준으로 전체 제품을 비교 가능하게 만든 지표
- **결승전(Tournament)**: 10개 배치별 1위 제품을 토너먼트 방식으로 재비교하여 최종 순위 결정

### 1.4 브랜드 분석과의 차이점

| 항목          | 브랜드 분석 (89개)          | 제품 분석 (50개)                    |
| ------------- | --------------------------- | ----------------------------------- |
| 분석 단위     | 브랜드명                    | 상품명 (풀네임)                     |
| 키워드 패턴   | "다이소 {브랜드}" 중심      | "{브랜드} {제품명}" + "다이소" 조합 |
| 앵커          | 세그먼트별 앵커 (손앤박 등) | 단일 앵커 (VT 리들샷 100)           |
| 다이소 브랜드 | 제외                        | **포함** (별도 키워드 템플릿) |
| 인사이트 수준 | 브랜드 포지셔닝             | 제품별 수요 & SKU 레벨 재고 전략    |

## 2. 결승전 결과 (토너먼트)

10개 배치 1위 제품을 준결승→결승 방식으로 축소하여 최종 순위를 결정하였다.

### 2.1 전체 결승전

| 순위        | 제품                    | 평균 ratio | 특징                             |
| ----------- | ----------------------- | ---------- | -------------------------------- |
| **1** | **VT 리들샷 100** | 49.54      | 2위 대비 9.2배, 압도적 검색 수요 |
| 2           | VT 시카 카밍            | 5.39       | 진정 케어 수요 기반              |

> VT 리들샷 100이 전체 50개 제품 중 검색량에서 **압도적 1위**. 브랜드 분석에서 VT가 하락 추세(43.2점)였음에도, 리들샷 100은 여전히 강력한 개별 제품 수요를 유지한다.

### 2.2 성별 결승전

| 세그먼트       | 1위                   | 2위                 |
| -------------- | --------------------- | ------------------- |
| **남성** | VT 리들샷 100 (54.70) | VT 시카 카밍 (7.66) |
| **여성** | VT 리들샷 100 (48.66) | VT 시카 카밍 (5.11) |

> 남녀 모두 VT 리들샷 100이 1위이나, **남성의 검색 비중이 6p 높다** → 남성 스킨케어 핵심 제품

> - **50~60대**: 본셉 레티놀 500 IU(안티에이징)가 2위, 특히 60대에서 9.03으로 높은 비중

## 6. 비즈니스 시사점

### 6.1 VT 리들샷 = 다이소 뷰티의 '앵커 상품'

- 브랜드 분석에서 VT는 하락 추세(정규화 43.2)였으나, **제품 분석에서는 리들샷 100이 정규화 100으로 압도적 1위**
- 브랜드 전체가 아닌 **리들샷 라인**에 검색 수요가 집중된 것
- 리들샷 100/300/500의 합산 정규화 = 186.4 → VT 검색의 대부분을 차지

### 6.2 연령별 '필수 SKU' 차별화

| 연령대  | 필수 SKU                                         | Hub 매장 권장            |
| ------- | ------------------------------------------------ | ------------------------ |
| 10대    | 에이솔루션 어성초 칼라민                         | 학교 근처 매장 재고 강화 |
| 20대    | VT 리들샷 100, 다이소 에그캡슐팩                 | 대학가 매장 재고 강화    |
| 30대    | VT 리들샷 100/300/500                            | 직장인 밀집 상권         |
| 40대    | VT 리들샷 100/300, 손앤박 아티 스프레드 컬러     | 주거 상권 + 색조 라인업  |
| 50~60대 | VT 리들샷 100/300, 본셉 비타씨 크림, 본셉 레티놀 | 기능성 코너 별도 구성    |

### 6.3 다이소 자체 브랜드 가능성

- 다이소 에그캡슐팩이 정규화 16.9로 **전체 7위** → 자체 브랜드 중 유일한 상위권
- 특히 **20대에서 4위**(29.9) → Z세대의 가성비 팩 수요 확인
- 자체 브랜드 확대 시 에그캡슐팩 성공 패턴(가성비 + 재미 요소)을 참고할 것

### 6.4 PC vs 모바일 차이

| 기기   | 특이 제품                     | 의미                              |
| ------ | ----------------------------- | --------------------------------- |
| PC     | 손앤박 아티 스프레드 컬러 2위 | 색조 제품은 PC에서 상세 정보 탐색 |
| 모바일 | VT 시카 카밍 2위              | 스킨케어는 모바일 빠른 검색 패턴  |

## 7. 방법론 상세

### 7.1 키워드 생성 (제품당 최대 20개)

```
A. 풀네임 조합 (5개)
  1. "{brand} {kw}"                    — VT 리들샷 100 페이셜 부스팅 퍼스트 앰플
  2. "다이소 {brand} {kw}"              — 다이소 VT 리들샷 100 ...
  3. "다이소 {kw}"                      — 다이소 리들샷 100 ...
  4. "{kw}"                             — 리들샷 100 ... (제품명만)
  5. "{kw} {brand}"                     — 리들샷 100 ... VT

B. 축약 조합 (4개)
  6. "{brand} {short_kw}"              — VT 리들샷 100
  7. "다이소 {brand} {short_kw}"        — 다이소 VT 리들샷 100
  8. "다이소 {short_kw}"               — 다이소 리들샷 100
  9. "{short_kw} {brand}"              — 리들샷 100 VT

C. 의도 키워드 (6개)
  10~12. "{brand} {short_kw} 추천/후기/리뷰"
  13~15. "다이소 {brand} {short_kw} 추천/후기/리뷰"

D. 속성 키워드 (5개)
  16~20. "{brand} {short_kw} 가격/가성비/효과/성분/사용법"
```

### 7.2 다이소 자체 브랜드 키워드

다이소 브랜드 제품은 `"다이소 {kw}"` 패턴 위주로 별도 생성.

### 7.3 groupName 충돌 해결

동일 브랜드의 유사 제품명 충돌 방지:

- 1차: `"{브랜드} {2단어}"`
- 2차: `"{브랜드} {3단어}"`
- 3차: `"{브랜드} {3단어} {product_code}"`

### 7.4 앵커 비교

- 브랜드 분석: 세그먼트별 다른 앵커 (ANCHOR_MAP)
- **제품 분석: 단일 앵커** (engagement 1위 = VT 리들샷 100)
  - 이유: 제품 단위에서는 세그먼트별 1위가 거의 동일(VT 리들샷 100)하므로, 단일 앵커가 일관된 비교 기준을 제공
