# 네이버 검색량 분석 - 전체 브랜드 (88개)

> 분석일: 2026-02-24 | 데이터: 네이버 검색 API (블로그/쇼핑/뉴스) | 대상: 다이소 뷰티 전체 브랜드

---

## 1. 분석 개요

### 1.1 목적

다이소 뷰티에 입점한 **전체 88개 브랜드**의 네이버 검색량을 측정하여, 브랜드별 온라인 관심도와 채널별 특성을 파악한다.

### 1.2 방법

| 항목 | 내용 |
|------|------|
| API | 네이버 검색 API (블로그/쇼핑/뉴스) |
| 키워드 | 브랜드당 19개 조합 (예: "다이소 VT", "다이소 VT 추천", "VT 다이소 후기" 등) |
| 지표 | 각 채널의 총 검색 결과 수 (절대값) |
| 총 API 호출 | 1,848회 |

### 1.3 노이즈 주의 브랜드

일반명사와 겹쳐 검색량이 과대 측정되는 브랜드가 존재한다. 해석 시 주의가 필요하다.

| 브랜드 | 블로그 | 노이즈 사유 |
|--------|--------|------------|
| 태그 | 30,641 | "다이소 태그" → 가격 태그, 이름표 등과 혼재 가능성 존재 |
| 펠트 | 16,632 | "다이소 펠트" → 공예 재료(펠트지)와 혼재 가능성 존재 |
| 머지 | 11,414 | "다이소 머지" → 뷰티 외 의미와 혼재 가능성 존재 |
| 식물원 | 10,168 | "다이소 식물원" → 식물/화분 관련과 혼재 가능성 존재 |

> 노이즈 가능성이 있으나 **제외하지 않고 전체 88개 브랜드를 포함**하여 분석한다. 해당 브랜드는 표에서 (노이즈 주의)로 표기한다.

## 5. 키워드 패턴 인사이트

### 5.1 의도별 키워드 합계 (전체 88개 브랜드)

| 의도 | 총 검색량 | TOP 3 브랜드 |
|------|----------|------------|
| 추천 | 195,419건 | 코드글로컬러(10,730), VT(6,479), 줌 바이 정샘물(5,812) |
| 후기 | 135,757건 | 코드글로컬러(7,133), VT(5,748), 더랩 바이 블랑두(3,159) |
| 리뷰 | 82,380건 | 코드글로컬러(4,820), 더랩 바이 블랑두(3,159), VT(3,533) |

> **코드글로컬러**는 블로그 기본 검색(644건)으로는 C-Tier이지만, "추천/후기/리뷰" 의도 키워드에서는 최상위 → **구매 의도가 매우 높은 브랜드**로 해석된다.

### 5.2 "다이소 {브랜드}" vs "{브랜드} 다이소" 패턴

대부분의 브랜드에서 **"다이소 {브랜드}"** 형태가 더 많이 검색된다. 이는 소비자가 **"다이소에서 {브랜드} 살 수 있나?"**라는 유통 채널 확인 의도로 검색하는 것을 의미한다.

예외적으로 **"머지 다이소"**(11,415) > "다이소 머지"(11,414)로, 머지는 브랜드 인지도가 먼저 형성된 후 다이소 입점을 확인하는 패턴이다.

## 6. 비즈니스 시사점

### 6.1 VT의 독보적 위치

- 노이즈 제외 시 블로그 실질 1위(11,026), 쇼핑 1위(267), 뉴스 3위(1,373)
- 모든 채널에서 골고루 강세 → **다이소 뷰티의 앵커 브랜드**
- 리들샷 시리즈가 핵심 견인 동력

### 6.2 "숨은 강자" 발굴

| 브랜드 | 현재 Tier | 숨은 강점 | 제안 |
|--------|----------|----------|------|
| 코드글로컬러 | C (644) | 추천/후기 키워드 1위 → 구매 의도 최고 | Tier 상향 잠재력 |
| 줌 바이 정샘물 | B (1,093) | "추천" 키워드 5,812건 | 마케팅 강화 시 A-Tier 가능 |
| 밀크터치 디어씽 | B (1,127) | 쇼핑 65건(5위) → 외부 유통 활발 | 다이소 전용 라인 차별화 |
| 더랩 바이 블랑두 | B (1,625) | 리뷰 키워드 상위 → 체험 후기 활발 | 체험 마케팅 효과적 |

### 6.3 PR 주도 vs 입소문 주도

| 유형 | 브랜드 | 전략 제안 |
|------|--------|----------|
| PR 주도 (뉴스/블로그 > 0.4) | LG생활건강, 더봄, 투에딧, 미모 바이 마몽드 | 소비자 체험 콘텐츠 확대 필요 |
| 입소문 주도 (뉴스/블로그 < 0.15) | VT(0.12), 바세린(0.01), 메디필(0.11) | PR 보완 시 시너지 가능 |

### 6.4 D-Tier 브랜드 관리

24개 브랜드(27.3%)가 블로그 500건 미만으로, 소비자 인지도가 매우 낮다. 특히 퓨어덤(23건), 플로르드망(90건), 멘넨(91건) 등은 검색이 거의 발생하지 않아 **SKU 효율화(정리) 후보**로 검토할 수 있다.
