# 네이버 검색량 분석 - 제품별 (engagement_score TOP 50)

> 분석일: 2026-02-25 (v2, 키워드 로직 개선) | 데이터: 네이버 검색 API (블로그/쇼핑/뉴스) | 대상: engagement_score 상위 50개 제품

---

## 1. 분석 개요

### 1.1 목적

브랜드 단위가 아닌 **개별 제품명** 기준으로 검색량을 측정하여, 어떤 제품이 실제로 소비자의 검색을 유도하는지 파악한다.

### 1.2 브랜드 분석과의 차이

| 항목        | 브랜드 분석                      | 제품 분석 (본 문서)                             |
| ----------- | -------------------------------- | ----------------------------------------------- |
| 키워드      | "다이소 VT", "다이소 VT 추천" 등 | "VT 리들샷 100 페이셜 부스팅 퍼스트 앰플" 등    |
| 단위        | 브랜드 88개                      | 제품 48개 (다이소 자체 제외)                    |
| 관점        | 브랜드 인지도                    | 제품별 검색 수요 + 구매 의도                    |
| 키워드 구성 | 브랜드당 19개 템플릿             | 제품당 9개 (풀네임 + 다이소 접두 + 의도 키워드) |

### 1.3 키워드 구성 (v2 개선)

제품당 최대 **9개** 키워드를 생성한다.

| # | 패턴                            | 예시 (VT 리들샷 100)                        | 용도                |
| - | ------------------------------- | ------------------------------------------- | ------------------- |
| 1 | `{brand} {kw}`                | VT 리들샷 100 페이셜 부스팅 퍼스트 앰플     | 풀네임 검색량       |
| 2 | `다이소 {brand} {short}`      | 다이소 VT 리들샷 100                        | 다이소 채널 인지도  |
| 3 | `다이소 {kw}`                 | 다이소 리들샷 100 페이셜 부스팅 퍼스트 앰플 | 다이소 + 핵심키워드 |
| 4 | `{brand} {short} 추천`        | VT 리들샷 100 추천                          | 구매 의도 (추천)    |
| 5 | `다이소 {brand} {short} 추천` | 다이소 VT 리들샷 100 추천                   | 다이소 구매 의도    |
| 6 | `{brand} {short} 후기`        | VT 리들샷 100 후기                          | 경험 탐색 (후기)    |
| 7 | `다이소 {brand} {short} 후기` | 다이소 VT 리들샷 100 후기                   | 다이소 경험 탐색    |
| 8 | `{brand} {short} 리뷰`        | VT 리들샷 100 리뷰                          | 상세 평가 (리뷰)    |
| 9 | `다이소 {brand} {short} 리뷰` | 다이소 VT 리들샷 100 리뷰                   | 다이소 상세 평가    |

**v1 대비 변경사항:**

- 키워드 3번: ~~`{kw}` (브랜드 제거, 일반명사 노이즈)~~ → `다이소 {kw}` (노이즈 해소)
- 의도 키워드 6개 신규 추가 (추천/후기/리뷰 x 다이소 유무)

### 1.4 분석 대상

- `engagement_score` = 0.15 x likes + 0.30 x shares + 0.55 x review_count
- 상위 50개 제품 → 다이소 자체 브랜드 제외 → **48개 그룹** (중복 제거 후 46개 고유 제품)
- 총 API 호출: 457회 (v1: 223회)
