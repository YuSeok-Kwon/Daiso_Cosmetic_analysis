# 네이버 검색 트렌드 분석 - 전체 브랜드 (89개)

> 분석일: 2026-02-24 | API: 네이버 DataLab 검색어 트렌드 | 대상: 다이소 뷰티 전체 브랜드

---

## 1. 분석 개요

### 1.1 목적

다이소 뷰티에 입점한 **전체 89개 브랜드**의 네이버 검색 트렌드를 성별·연령대·기기별로 분석하여, 세그먼트별 소비자 관심도와 브랜드 포지셔닝을 파악한다.

### 1.2 방법론

| 항목        | 내용                                                                           |
| ----------- | ------------------------------------------------------------------------------ |
| API         | 네이버 DataLab 검색어 트렌드 (`/v1/datalab/search`)                          |
| 키워드      | 브랜드당 19개 OR 조합 (예: "다이소 VT", "VT 다이소 추천", "다이소 VT 후기" 등) |
| 지표        | **상대 검색량 ratio** (배치 내 최고값=100 기준 상대비율)                 |
| 기간        | 2024-01-01 ~ 2026-01-31 (월 단위)                                              |
| 세분화      | 성별(남/여), 연령대(10대~60대), 기기(PC/모바일)                                |
| 총 API 호출 | 243회                                                                          |

### 1.3 핵심 용어

- **ratio**: 네이버 DataLab이 제공하는 상대 검색량. 배치(5그룹) 내에서만 직접 비교 가능
- **앵커 정규화**: 모든 배치에 동일 앵커 브랜드를 포함시켜, 앵커=100 기준으로 전체 브랜드를 비교 가능하게 만든 지표
- **결승전(Tournament)**: 18개 배치별 1위 브랜드를 토너먼트 방식으로 재비교하여 최종 순위 결정

### 1.4 데이터 정제

`brands.parquet`에서 이상치를 제거 후 실행하였다.

| 변경 유형   | 브랜드명    | 사유                                        |
| ----------- | ----------- | ------------------------------------------- |
| 제거        | 녹차        | 일반명사 → 검색 노이즈                     |
| 제거        | 비타민C     | 일반명사 → 검색 노이즈                     |
| 제거        | 약산성      | 일반명사 → 검색 노이즈                     |
| 제거        | 프롬더스킨  | "프롬 더 스킨"과 중복                       |
| 제외 (기존) | 포인트      | 일반명사 → 완전 제외 (`_EXCLUDE_BRANDS`) |
| 제외 (기존) | ALL, 다이소 | 메타 브랜드 → 자동 제외                    |

**최종 분석 대상**: 92개 - 3개(제거) = 89개 키워드 그룹 → 18배치

## 8. 방법론 상세

### 8.1 배치 처리

네이버 DataLab API는 1회 호출에 최대 5개 키워드 그룹만 허용한다. 89개 브랜드를 분석하기 위해:

1. **기본 호출**: 89그룹 → 18배치 (5개씩)
2. **세분화 호출**: 성별(2) + 연령대(6) + 기기(2) = 10종 × 18배치
3. **결승전**: 18개 배치 1위 → 토너먼트(준결승) → 최종 결승 (세분화별 반복)
4. **앵커 비교**: 앵커 + 4개씩 → 11종 × ~22배치

### 8.2 토너먼트 시스템

배치 수 > 5인 경우 결승전을 바로 실행할 수 없으므로:

```
18개 배치 1위
    ↓ 준결승 (4배치 → 4개 1위)
4개 최종 결승
    ↓ 1회 API 호출
최종 순위 결정
```

### 8.3 앵커 정규화 원리

```
배치 A: [앵커(30), B(50), C(10), D(20)]  → B=167, C=33, D=67 (앵커=100)
```
