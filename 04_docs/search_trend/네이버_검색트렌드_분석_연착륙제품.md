# 네이버 검색 트렌드 분석 - SLI 상위 10% 연착륙 제품 (146개)

> 분석일: 2026-02-27 | API: 네이버 DataLab 검색어 트렌드 | 대상: SLI 상위 10% 연착륙 제품 146개 중 검색 트렌드 수집 성공 78개

---

## 1. 분석 개요

### 1.1 목적

SLI(Soft Landing Index) 상위 10%로 분류된 **연착륙 제품 146개**의 네이버 검색 트렌드를 분석하여, **장기 안정성이 검증된 제품들의 검색 수요 패턴**을 파악하고, 세그먼트별(성별·연령·기기) 선호도 차이를 도출한다.

### 1.2 방법론

| 항목        | 내용                                                                              |
| ----------- | --------------------------------------------------------------------------------- |
| API         | 네이버 DataLab 검색어 트렌드 (`/v1/datalab/search`)                             |
| 대상 제품   | SLI 상위 10% 연착륙 제품 146개                                                    |
| 수집 성공   | **78개 제품** (53.4% 수집률)                                                |
| 키워드      | 제품당 최대 20개 OR 조합 (풀네임 5 + 축약 4 + 의도 6 + 속성 5)                    |
| 지표        | **평균 ratio** (세그먼트별 배치 내 상대 검색량)                             |
| 기간        | 2024-01-01 ~ 2026-01-01 (월 단위)                                                 |
| 세분화      | 성별(남/여), 연령대(10대~60대), 기기(PC/모바일)                                   |
| 총 세그먼트 | 672개 (전체 78 + 성별 137 + 연령 355 + 기기 102)                                   |

### 1.3 핵심 용어

- **SLI(Soft Landing Index)**: 출시 초반 붐 이후에도 급격히 무너지지 않고, 중기~장기 구간에서 안정적으로 유지되며, 일정 규모 이상의 시장 기여도를 갖는 제품의 연착륙 지수
- **연착륙 제품**: SLI 상위 10% (146개 제품), 전체 매출의 40.8% 기여, 평균 가격 4,063원, 스킨케어 비중 69.6%
- **avg_ratio**: 세그먼트별 배치 내 평균 상대 검색량. 배치(5그룹)마다 최고값=100 기준
- **결승전(Tournament)**: 세그먼트별 상위 제품들을 비교하여 최종 순위 결정

### 1.4 수집 현황

| 구분            | 수량  | 비율    |
| --------------- | ----- | ------- |
| 총 연착륙 제품  | 146개 | 100.0%  |
| 검색 트렌드 수집 성공 | 78개  | 53.4%   |
| 검색 트렌드 없음 | 68개  | 46.6%   |

> 68개 제품은 검색량이 너무 낮아 네이버 DataLab에서 데이터를 제공하지 않음. 이는 오프라인 매장에서 직접 구매하는 "즉흥 구매" 패턴이거나, 브랜드명보다 제품 속성으로 검색되는 경우로 추정.

## 2. 결승전 결과 (토너먼트)

세그먼트별 평균 ratio 기준 상위 1-2위 제품을 선정하였다.

### 2.1 전체 결승전
