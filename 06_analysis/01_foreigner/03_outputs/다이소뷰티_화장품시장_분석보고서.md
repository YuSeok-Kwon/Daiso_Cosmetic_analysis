## 1. 분석 개요

### 1.1 분석 목적

다이소 뷰티의 지속 가능한 성장을 위해 **서울시 화장품 시장**과 **외국인 밀집지역**을 결합 분석하여, 최적의 상권 전략(Hub & Spoke)을 수립한다.

### 1.2 활용 데이터

| 데이터 | 출처 | 기간 | 규모 |
|--------|------|------|------|
| 다이소 제품 | 다이소몰 크롤링 | 2024년 | 954개 제품 |
| 다이소 리뷰 | 다이소몰 크롤링 | 2023~2025년 | 323,493개 리뷰 |
| 서울 화장품 매출 | 서울시 상권분석서비스 | 2024년 1~4분기 | 2,040개 상권 |
| 외국인 생활인구 | 서울 열린데이터광장 | 2025년 | 25개 자치구 |

## 5. Hub & Spoke 전략 제언

### 5.1 전략 개요

```
┌─────────────────────────────────────────────────────────────┐
│                    Hub & Spoke 모델                         │
├─────────────────────────────────────────────────────────────┤
│  HUB (관광 상권)          │  SPOKE (거주 상권)              │
│  • 외국인 밀집 지역        │  • 주택가 인근 상권              │
│  • 연착륙 스킨케어 집중    │  • 다양한 제품 구색              │
│  • 재고 심도 5~10배       │  • 테스트 환경 제공              │
│  • 다국어 서비스          │  • 정기 구매 유도                │
└─────────────────────────────────────────────────────────────┘
```

## 6. 핵심 인사이트 요약

### 6.1 시장 기회

| 발견 | 의미 |
|------|------|
| 관광특구 상권당 매출 66.6억 | 일반 상권 대비 5배 → 집중 투자 필요 |
| 중구 외국인 90만명/일 | 명동 = 최우선 HUB 상권 |
| VT 리들샷 재구매율 65% | 외국인 필수 추천 제품 |
| 여성 65%, MZ 35% | 타겟 명확 |
| 14~17시 피크타임 | 재고 관리 시간대 |

### 6.2 실행 제언

#### 단기 (1~3개월)

1. **명동 매장 집중 강화**
   - VT 리들샷 시리즈 재고 5배 확보
   - 중국어/일본어/영어 POP 설치
   - 14~17시 추가 인력 배치

2. **연착륙 TOP 10 제품 전면 진열**
   - 입구 진열대 최우선 배치
   - "재구매율 60%" 스티커 부착

#### 중기 (3~6개월)

3. **HUB 상권 확대**
   - 강남역, 신사역, 학동사거리 동일 전략 적용
   - 외국인 밀집 시간대 모니터링

4. **SPOKE 상권 구색 최적화**
   - 성수동, 송리단길: 트렌디 신제품 테스트
   - 양천향교: 40대+ 타겟 안티에이징 강화

#### 장기 (6개월~)

5. **데이터 기반 재고 관리**
   - 상권별 매출 데이터 연동
   - 외국인 생활인구 실시간 모니터링
   - 계절/시간대별 재고 자동 조정
