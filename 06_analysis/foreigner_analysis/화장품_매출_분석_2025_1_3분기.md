## 2. 상권유형별 분석

### 2.1 상권 구분

|    코드    | 상권유형 | 특징                             | 전략                   |
| :---------: | -------- | -------------------------------- | ---------------------- |
| **A** | 골목상권 | 소규모 골목 상권, 가장 많은 비중 | Spoke 전략 (구색 위주) |
| **D** | 발달상권 | 역세권/대형 상권                 | Hub 전략 (재고 심도)   |
| **R** | 전통시장 | 관광 상권 포함 (홍대 등)         | Hub 또는 혼합 전략     |

### 2.2 상권유형별 매출 특성

- **골목상권(A)**: 거주 밀집 지역, 생활밀착형 소비
- **발달상권(D)**: 유동인구 많음, 충동구매 비중 높음
- **전통시장(R)**: 홍대소상공인상점가 등 관광 상권은 외국인 매출 비중 높음

## 4. 시간대/요일별 매출 패턴

### 4.1 요일별 매출

| 구분                  | 비중      | 특징                     |
| --------------------- | --------- | ------------------------ |
| **주중(월~금)** | 약 60~70% | 직장인/학생 퇴근 후 구매 |
| **주말(토~일)** | 약 30~40% | 쇼핑 목적 외출           |

### 4.2 시간대별 매출

| 시간대            | 주요 고객층             |
| ----------------- | ----------------------- |
| 06~11시           | 출근 전 구매, 비중 낮음 |
| **11~14시** | 점심시간, 높은 비중     |
| **14~17시** | 오후 쇼핑, 최고 비중    |
| 17~21시           | 퇴근 후 구매            |
| 21~24시           | 심야, 일부 상권만       |
